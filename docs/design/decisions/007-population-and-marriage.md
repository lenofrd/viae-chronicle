# ADR 007：人口由资源承载、婚姻依托认知关系与家庭协商

- **状态**：Accepted
- **日期**：2026-11-19
- **适用范围**：跨地点通用机制；溪古镇作为首个落地点

## 1. 背景与上下文

溪古镇长程模拟显示，固定人口阈值会直接阻断生育，而婚姻流程仍以自动筛选和家庭合并为主。现有生命历程设计还包含单户人数上限、婚后资产与债务整体合并等规则；认知系统已经具备人物相识阶段和近期互动记忆，但婚姻选择尚未使用这些信息。

本决策要求沿用现有 AgentState、HouseholdState、认知记忆、资源库存、事件日志和 Replay 基础，以小步调整替代新建平行系统。

## 2. 决策

### 2.1 人口与家庭不设人数硬上限

1. 不设置全镇总人口硬上限；人口达到某个固定数字不得成为禁止出生或婚姻的理由。
2. 不设置单个家庭成员人数硬上限；家庭人数不得因固定容量值而被静默拒绝。
3. 人口规模由真实资源供给和消耗共同决定，包括食物、饮水、住房、生产能力、医疗与公共服务等。
4. 人口增加会增加家庭及公共资源消耗；供给不足通过饥饿、健康、居住条件、服务等待和死亡等机制体现。
5. 住房、土地、公共服务仍有真实的空间与吞吐约束，但这些约束影响居住条件、等待、建设和迁居选择，不转化为全镇人口或家庭成员数的全局硬上限。
6. 不因取消人口上限而凭空生成土地、建筑、食物、水或其他资源。

### 2.2 婚姻使用已有认知系统

1. 婚姻候选人必须具有真实的社会接触基础；优先读取双方已有的 acquaintances 认知阶段及 recent_interactions 互动记忆。
2. 婚姻判断应考虑双方是否认识彼此，而不是仅凭性别、年龄、健康、家庭库存和空间距离自动配对。
3. “认识”不等于“喜欢”，“熟悉”不等于“同意结婚”。本阶段不强行引入完整恋爱数值或复杂情感状态机。
4. 认知与互动记忆为未来的好感、信任、感情培养、求婚与拒绝提供接口；后续扩展复用现有关系和互动系统。
5. 亲属禁婚等基本限制继续有效。年龄、健康、距离和家庭经济状况用于判断婚姻是否合适，不应以不必要的家庭存粮硬门槛取代社会关系判断。

### 2.3 从夫居与成员迁移

1. 婚姻成立后，女方本人迁入男方家庭，成为该家庭成员。
2. 女方以家庭成员身份参与日常生活和劳动；其劳动由现有行动、工作分配与生产机制自然体现，不额外强制指定劳动。
3. 婚后出生的子女加入夫妻共同生活的家庭。女方此前已有子女的迁移与监护另行明确，不因婚姻自动迁移或转移财产。
4. 女方原家庭保留其他成员、住所、资产、债务和家庭身份；不得因为女方出嫁而自动解散。

### 2.4 彩礼与财产边界

1. 男方家庭向女方原家庭支付彩礼。彩礼是婚姻协商中的家庭间资产转移，不是系统凭空生成的费用。
2. 彩礼不设全镇统一固定金额；双方家庭根据各自经济状况、资源储备、债务、劳动力变化和婚姻意愿衡量并协商。
3. 彩礼支付不得把男方家庭推入明显无法维持基本生存的状态；女方家庭也不因一个固定最低金额而被系统强制接受或拒绝。
4. 女方原家庭决定是否安排陪嫁、安排何种财产及数量。陪嫁是独立于彩礼的可选转移，不默认发生。
5. 女方本人迁入男方家庭，不代表女方原家庭资产或债务整体转入男方家庭。
6. 任何彩礼、陪嫁或其他婚前财产转移必须逐项、明确、守恒并写入事件；未明确约定的财产留在原家庭。
7. 当前 Household 是资产与债务的经济归属单位；本决策不假设女方已有独立个人资产账户。

### 2.5 兼容与实施原则

1. 沿用现有家庭合并、成员迁移、婚姻事件、资源库存、认知关系与 Replay 投影，优先做局部调整。
2. 不另建第二套家庭状态机、婚姻状态机或认知系统。
3. 旧生命历程文档中关于婚后资产/债务整体合并、家庭成员容量硬上限的规则，以本 ADR 和对应系统设计更新为准。
4. 所有资产转移、婚姻成立、家庭成员变化均须事件化并可 Replay。
5. 本决策定义目标行为，不代表所有目标已经在运行时代码中实现。现阶段先以双方互相达到 known 作为婚姻候选门槛，暂不新增完整恋爱/求婚状态机；known 不代表同意，后续在候选与登记之间补入意愿和议婚环节。

## 3. 后果与影响

### 优势
- 人口不再被任意阈值截断，人口规模能够响应资源生产、分配和消耗。
- 婚姻建立在可追溯的社会接触上，为感情培养和家庭协商留出自然扩展空间。
- 从夫居、彩礼和陪嫁成为可解释的家庭间经济关系。
- 女方迁移与女方原家庭财产边界清晰，避免婚姻造成无条件资产吞并。
- 继续复用现有 Household、认知、关系、事件和 Replay 机制。

### 风险与约束
- 取消人数上限后，资源短缺会更真实地影响人口，但也更依赖资源生产、家庭分配和公共服务机制的正确性。
- 不设家庭人数硬上限后，住房拥挤和服务容量必须通过真实状态表达，不能静默忽略。
- 认知状态当前较简化，初期只能表达相识/熟悉基础，不能把它误称为完整恋爱或双向好感系统。
- 彩礼估值和协商应先采用可解释的简化规则，避免一次引入复杂议价系统。

## 4. 不在本决策中固定的事项

- 人口资源承载能力的具体公式和各项地点参数。
- 相识所需互动次数、认知阶段门槛和记忆保留参数。
- 好感、爱情、求婚、拒绝、家庭议婚等后续情感机制。
- 彩礼估值系数、谈判轮数、地方习俗差异和具体支付物品。
- 陪嫁的具体范围、女方既有子女的监护与迁移规则。
- 个人财产制度、婚后继承制度及其他婚姻形态。
