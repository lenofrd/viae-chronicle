# 溪谷镇（Brookvale）总览

## 1. 世界定位与基调
溪谷镇位于北域青冥山脉外围的山脚冲积平原上。这是一个纯凡人的农耕聚落，生活自给自足。
**修仙元素背景**：镇子背后的青冥山深处属于“修仙界”的势力范围，偶尔会有御剑飞行的修士掠过天际，或是有受伤的低阶妖兽从深山逃出。镇民对深山充满敬畏，山中有“灵药”与“神树”的传说，但普通人不敢深入。第一版模拟以凡人的柴米油盐为主，修仙元素作为“环境异象”或“远方传说”存在。

## 2. 核心矛盾
- **生存压力**：凡人耕种靠天吃饭，旱涝都会引发水权与地界纠纷。
- **阶级压迫**：镇上有里正和地主，底层帮工和寡妇生活艰难。
- **神秘敬畏**：偶尔的山洪或野兽下山，会被老一辈解释为“山神发怒”或“妖兽作祟”，触发宗教仪式。

## 3. 地理位置
- **北面**：高耸入云的青冥山（凡人可达山脚、浅山；深山凡人止步）。
- **南面**：自西向东流淌的“翠溪”（宽河，提供灌溉和渔获）。
- **中心**：溪谷镇中心（祠堂、水井、磨坊、里正家）。
- **东西**：东面是肥沃的水浇稻田，西面是易旱的旱地和坡地。
