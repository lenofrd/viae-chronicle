# 溪谷镇 - 开局潜在的定时炸弹

*这些矛盾在开局时处于“潜伏”状态，随着环境或人物的交互，会逐渐引爆。*

## 1. 水权危机（即将引爆）
由于 15 天未下雨，西片田的旱地已经干裂。
- **触发条件**：如果再持续 5 天不下雨，林远等西片贫户将面临绝收。
- **预期冲突**：林远可能会去向李全求水，或者被逼无奈去偷偷破坏水渠。

## 2. 寡妇的危机（随时爆发）
赵翠兰的婆家（赵大）一直盯着她那一亩水浇地。
- **触发条件**：赵大可能会在集市或水井边散播赵翠兰“不守妇道”的谣言，试图用舆论逼迫她交出田地。

## 3. 青年的困局（慢线）
林远想拜张木匠为师。
- **触发条件**：林远如果在农闲时间去张木匠处帮忙，可能会引起母亲陈氏的不满，引发家庭争吵。

## 4. 游商的到来（外部刺激）
货郎赵老七将在第 3 天来到镇上。
- **触发条件**：他会带来盐价上涨的消息，并可能会借此引诱赵翠兰，或者向林远兜售不知名的深山药草种子。
