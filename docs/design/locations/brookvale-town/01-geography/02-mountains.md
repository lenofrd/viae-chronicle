# 青冥山（外围） - 大山设定

## 1. 大山层次（从外到内）
为了体现“广阔与现实感”，大山分为三层：

### 1.1 山脚（凡人的日常资源区）
- **特征**：地势较缓，灌木丛生，有镇民踩出的土路。
- **产出**：柴薪（日常燃料）、常见草药（车前草、蒲公英）、野果。
- **危险**：蛇虫、野猪（偶尔下山破坏庄稼）。
- **耗时**：从镇中心步行约 1 个时辰。

### 1.2 浅山（猎户与采药人的冒险区）
- **特征**：林木参天，云雾开始变多。有溪流从山中流下。
- **产出**：柴胡、半夏、石斛等珍贵草药，小型猎物（野兔、鹿）。
- **危险**：迷路、狼群、陡峭的滑坡点。
- **耗时**：从山脚出发，约半天时间（2-3 个时辰）才能到达。

### 1.3 深山（凡人禁区 / 修仙界边缘）
- **特征**：常年浓雾，有“阵法”痕迹，异兽嘶吼。传说有修士在此洞府修炼。
- **产出**：灵芝、百年灵药、陨铁（第一版凡人极难获取）。
- **危险**：瘴气（必死）、妖兽、迷障（走不出来）。
- **耗时**：从浅山深入需 1 天以上，且九死一生。
- **环境事件**：偶尔夜间会出现“剑光”划破天际，或深山传来巨响（修士斗法或异兽突破）。

## 2. 山上的标志物
- **山神庙**：位于山脚，供奉不知名的“山神”。镇民祭拜祈求平安，实则是早年修士留下的道统残骸，早已无人认识。
- **神树（千年银杏）**：长在山脚与浅山交界处，被镇民视为山神化身，严禁砍伐。
- **滑坡点**：浅山有一处大滑坡，曾掩埋过进山采药的人，现成为禁忌之地。

## 3. 资源与冲突
- 过度砍伐山脚柴薪，会导致生态退化，镇民被迫冒险进入浅山。
- 严禁私自进入深山，违反者会被村规重罚（因为可能会引来妖兽或惹怒仙人）。
