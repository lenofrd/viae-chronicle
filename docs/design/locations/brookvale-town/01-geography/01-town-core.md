# 溪谷镇 - 镇内节点与聚落分区

## 1. 镇内核心场景（公共/半公共空间）

镇子沿山脚、河岸与既有道路节点展开，核心区步行可达。节点 ID、相互连接和移动耗时以 `config/worlds/brookvale-town-001/spatial-units.yaml` 为运行时配置依据；本文描述其社会用途，不另造平行坐标系统。

### 1.1 祠堂（镇中心）

- 外观：青砖灰瓦，供奉祖宗牌位与残破石碑。
- 功能：祭祖、全村议事、公开宣告和村规执行。
- 开放：日常由公共管理者保管；节日、议事或公共事件时开放。
- 社会意义：公共权威和集体记忆的象征。

### 1.2 里正家（镇中心，紧邻祠堂）

- 外观：镇里较好的青砖大瓦房。
- 功能：基层事务处理、文书保管、接待差役和居民申诉。
- 制度边界：里正家是现有空间节点，不等于里正身份、选任或任期机制已经实现。治理机制见 `04-rules/01-village-rules.md` 与 systems 文档。

### 1.3 水井（镇中心）

- 功能：日常取水、洗衣和信息交换。
- 社会意义：镇内重要公共活动与消息汇集点。
- 风险：旱季水位下降，雨季可能倒灌。

### 1.4 集市空地（祠堂东侧）

- 功能：赶集、货郎摆摊和日常交易。
- 社会意义：盐、铁、布匹和外界商品的交换节点。

### 1.5 药铺（镇中心偏东）

- 功能：看病、抓药、收购草药。
- 社会意义：医疗服务与山间消息汇集点。

## 2. 居住区

既有空间节点包括富户区、平民区和贫民区。其初始位置、移动成本和居民分布以现有节点配置及人口文档为准：

- 富户区：既有配置位于镇东，靠近集市。
- 平民区：既有配置位于镇中，靠近水井。
- 贫民区：既有配置位于镇西，靠近山脚；其与河渔节点的近路是既有移动拓扑的一部分。

上述分布表达开局历史与交通差异，不得固化为禁止跨区居住的制度。家庭可通过继承、买卖、租赁、分家和迁居改变居住位置。

## 3. 地块与建筑空间约束

土地空间采用通用三层模型：TerrainCell 表达地形环境，LandParcel 表达边界、用途和权利，Building 表达建筑实体与实际 footprint。具体规则见 `systems/human-environment/01-social-spaces/05-land-parcels-and-buildings.md`。

- 宅基地按院落整体登记；住宅、柴棚、储物棚和菜地可在同一地块内，但建筑 footprint 不得重叠。
- 农田按可耕作边界、地力和灌溉关系登记。
- 道路、水渠、河岸和公共通道的通行权独立登记，不因相邻地块私有而消失。
- 保护地不得被普通地块切分后规避保护规则。
- 边界不清时标记争议；争议范围内暂停不可逆施工和权利转让。

## 4. 选址与发展空间

建造选址需检查土地权利、用途、可建设面积、坡度排水、洪水与滑坡风险、野兽和火灾风险、道路/水井/工作资源可达性，以及对农田、水渠、河岸和邻地的影响。

空置住宅槽位不等于无主公共土地。聚落扩展优先使用具有明确权属和合法用途的地块，不允许因居民需求而凭空生成土地。

## 5. 验收条件

1. 里正家、祠堂、水井、集市、药铺及居住区继续使用现有节点身份。
2. 不以新增地点 ID 或另一套坐标拓扑替代 Brookvale 现有空间图。
3. 私人建筑不得重叠、越界或阻断既有道路、水渠和河岸通行。
4. 住宅分区是初始格局，不形成永久阶层隔离。
5. 地块、建筑与地形环境分别建模。
