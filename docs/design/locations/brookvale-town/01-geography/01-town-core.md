# 溪谷镇 - 镇内节点

## 1. 镇内核心场景（公共/半公共空间）
镇子沿着山脚和河岸之间的一条土路展开，核心区不大，步行一刻钟能走穿。

### 1.1 祠堂（镇中心偏北，地势最高）
- **外观**：青砖灰瓦，供奉着不知名的祖宗牌位与一块残破的石碑（传说是仙人留下的）。
- **功能**：祭祖、全村议事、重大惩罚（公开杖责或罚跪）。
- **开放度**：平时大门紧闭，由里正或族长保管钥匙。重大节日或发生命案/偷盗时开放。
- **社会意义**：权力的象征。在祠堂前被罚，是全镇皆知的公开羞辱。

### 1.2 里正家（镇中心，紧挨祠堂）
- **外观**：镇里少有的青砖大瓦房。
- **功能**：处理日常纠纷、收税、接待外来差役或货郎。
- **在场者**：里正、里正家属、来告状的村民。

### 1.3 水井（镇中心十字路口）
- **外观**：一口青石砌的深井，旁边有大柳树和几块搓衣石。
- **功能**：日常取水、洗衣、洗菜。
- **社会意义**：全镇最大的“信息交换中心”。妇女们在这里传闲话，男人在这里交换外界消息。
- **危险**：旱季水位下降，可能干涸。

### 1.4 集市空地（镇南，靠近渡口）
- **外观**：一块压实的黄土地，散落着废弃的木棚。
- **功能**：每逢农历初五、初十有“赶集”。外地货郎在此摆摊。
- **社会意义**：交易盐、铁、布匹和外界商品。贫富差距在这里最明显。

### 1.5 药铺（镇东，靠近东片田）
- **外观**：两间土房，门前晒着各种草药。
- **功能**：看病、抓药、认药。
- **在场者**：郎中、学徒、生病的村民。

## 2. 居住区（私人空间）
### 2.1 富户区（镇北，靠近祠堂和山脚）
- 里正、大地主、大宗族长辈的宅院。有院墙，有的还养了看门狗。存粮充足。

### 2.2 平民区（镇中，水井周围）
- 普通自耕农、工匠（铁匠、木匠）的土坯房。几户共用一个院子。

### 2.3 贫民区（镇西，靠近西片田）
- 帮工、佃户、寡妇、外来流民的茅草屋。一遇暴雨容易漏水倒塌。
