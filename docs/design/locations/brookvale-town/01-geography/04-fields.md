# 稻田与田地分布

## 1. 田地分类
### 1.1 东片田（水浇地）
- **位置**：靠近翠溪与镇中心，地势平坦。
- **特点**：有主水渠连接翠溪，灌溉充足，地力肥沃。
- **作物**：水稻（主粮）。
- **归属**：多属于里正、富户和几家老自耕农。是全镇最重要的命脉。

### 1.2 西片田（旱地/坡地）
- **位置**：镇西，远离河流，需要靠水车或挑水灌溉。
- **特点**：土质较差，灌溉不足，坡地较多。
- **作物**：小麦、粟米、麻、豆类。
- **归属**：多为贫户、寡妇和帮工开垦的薄田。

## 2. 水利设施
- **水渠**：从翠溪上游（磨坊附近）引出，横穿东片田。
- **水车**：用于将低处河水提升到高处田地（效率低，易坏）。
- **水井**：镇中心有一口深井，供全镇生活用水；西片田有部分旱井。

## 3. 田地属性与生态
- **地力**：需要轮耕、休耕或施肥（家畜粪便、河泥）。
- **灾害风险**：东片田怕洪（水淹），西片田怕旱（干裂）。
