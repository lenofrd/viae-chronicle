# 溪谷镇 - 田地、土地分区与初始地块规划

## 1. 既有田地节点

运行时空间节点沿用 `config/worlds/brookvale-town-001/spatial-units.yaml`：

### 1.1 东片田（east_field）

- 位置：镇东，靠近翠溪与镇中心，地势相对平坦。
- 特点：灌溉便利，地力较好。
- 作物：以水稻等水浇作物为主。
- 历史权属：既有背景设定中多属于地主、富户和老自耕农；具体权属必须落到家庭或集体地块记录，不能仅由“区域”推断。

### 1.2 西片田（west_field）

- 位置：镇西，坡地较多，距主要灌溉设施较远。
- 特点：土质和灌溉条件较差。
- 作物：既有配置将其设为蔬菜生产节点；后续轮作可由地力和季节规则决定。
- 历史使用：贫农耕作较多，但不构成永久使用权。

### 1.3 南片田（south_field）

- 位置：镇南、翠溪下游附近。
- 特点：灌溉便利。
- 历史权属：既有空间配置描述为里正李全名下自耕田；在土地权属系统落地时应迁移为明确的 LandParcel 权利记录。

## 2. 三类空间用途

| 分区 | 主要用途 | 建设与使用规则 |
|---|---|---|
| 河道 | 自然水体 | 禁止私人建筑 |
| 河岸 | 渡口、捕鱼、公共通行 | 仅允许与河岸功能相容且取得许可的设施 |
| 水浇田 | 灌溉农田 | 原则上保持农业用途；改住宅或作坊须重大用途变更决议 |
| 坡旱地 | 雨养农田、轮作、蔬菜 | 原则上保持农业用途 |
| 聚落核心 | 住宅、道路、集市、公共地标 | 依地块权属、用途和规划建设 |
| 山脚林地 | 柴薪和日常采集 | 采集权不等于开垦权 |
| 浅山密林 | 草药、硬木、猎物 | 生产使用受资源规则限制，普通住宅原则上不进入 |
| 深山禁区 | 特殊生态与异象 | 禁止常规采集、道路和私人建设 |
| 神树保护地 | 神树及周边 | 特殊保护，禁止普通私人开发 |

分区是用途审查依据，不代替具体地块的产权、边界和面积记录。

## 3. 地块划分与权利表达

- 一块地可覆盖多个地形单元；地块 ID、面积、用途和边界须独立记录。
- 宅基地按院落整体划分；住宅、柴棚、菜地和院落可属于同一地块。
- 农田按可耕作边界和灌溉关系划分。
- 道路、水渠和公共通道作为线性空间或通行权登记。
- 河岸可划分公共使用区与经许可的专用使用区。
- 山林采集区不等于可私有化林地。
- 保护地不得通过拆分地块规避保护规则。

权利类型分开记录：所有权、使用权、用益权、通行权、用途许可和管理权。宅基地家庭所有；私有田地可由家庭所有；集体田地由村落集体持有并分配或出租。

## 4. 初始空间与权属基线

土地制度设计的目标基线为 12 块水浇田、9 块坡旱地；具体地块边界、权属主体和坐标须由 Brookvale 既有世界配置扩展，不在本文虚构格网坐标。

- 初始住宅槽位 40 处，其中 30 处由 30 户占用，另 10 处空置。
- 每处空宅必须有明确产权：可为集体持有的可分配宅基地，也可为有私人产权但暂时空置的宅基地；不得默认为无主地。
- 贫民、平民、富户的初始空间分布保留为历史格局，不设永久居住区隔离。
- 迁居、交易、继承和租赁可改变空间格局。

## 5. 选址与用途变更

建造选址必须检查地块权属和用途、地形与排水、洪水和滑坡风险、道路与水渠通行、邻地影响及建筑 footprint。水浇田和坡旱地原则上维持农业用途；农田转住宅或作坊属于重大用途变更，须家庭代表议事会批准。

## 6. 验收条件

1. 继续沿用 east_field、west_field、south_field 既有节点。
2. 地块数量和边界不得与现有田地节点混为一谈；一个节点可包含多个地块。
3. 空宅与可自由开发土地严格区分。
4. 私人建筑不得阻断道路、水渠和河岸通行权。
5. 深山禁区和神树保护地不出现普通私人建设。
