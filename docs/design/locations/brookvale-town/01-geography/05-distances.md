# 溪谷镇 - 空间拓扑与移动耗时

## 1. 时间单位换算
系统设 1 Tick = 1 天。为了计算移动成本，将 1 天的时间划为 **10 个标准单位（Time Units, TU）**（类似于“时辰”）。
- 往返耗时超过 10 TU，说明当天无法返回，需要在外过夜（第一版深山设定）。

## 2. 核心节点耗时矩阵（以镇中心水井为起点）

| 目的地 | 单程耗时 (TU) | 步行难度 | 沿途风险 |
|---|---|---|---|
| 祠堂 / 里正家 | 0.5 | 平地 | 无 |
| 东片田 | 1.5 | 平地 | 无 |
| 西片田 | 2.5 | 坡地，难走 | 无 |
| 翠溪渡口 | 1.0 | 平地 | 汛期有溺水风险 |
| 山脚（山神庙/神树） | 2.0 | 缓坡 | 野兽下山时危险 |

## 3. 离开镇域的外部耗时

| 目的地 | 出发地 | 单程耗时 (TU) | 难度与风险 |
|---|---|---|---|
| 浅山（采药/打猎） | 山脚 | 4.0 | 山路崎岖，有迷路、蛇虫、野狼风险 |
| 深山（凡人禁区） | 浅山 | 8.0 | 浓雾、瘴气、妖兽。第一版不精细模拟，凡人通常有去无回。 |
| 外界（其他城镇） | 翠溪渡口 | 未知 | 需乘船或走远路，第一版不做具体模拟，仅作为“货郎来的方向”。 |

## 4. 距离对人物决策的影响
- 农夫去东片田干活：来回 3.0 TU，加上劳作 5.0 TU，刚好是一天的活计，晚上能回家。
- 如果农夫住在镇西（贫民区），去东片田干活，光走路就要 4.0 TU，劳作时间大幅缩水，这就是**地理位置带来的阶级壁垒**。
- 去浅山采药：来回 12.0 TU（超过一天），必须带上干粮，且晚上要在山里过夜，死亡率极高，所以只有最穷的人（为了钱）或最勇敢的猎户才会去。
