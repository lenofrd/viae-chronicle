# 溪谷镇 - 自然环境资源点

## 1. 柴薪林（山脚）
- **位置**：镇北山脚，走路约 2 TU。
- **产出**：普通柴薪。
- **再生率**：快（每月恢复）。
- **危险**：低（偶尔有野狗）。

## 2. 草药点
### 2.1 车前草/蒲公英（田埂/山脚）
- **采集难度**：低，任何人可采。
- **价值**：低（治小病）。
### 2.2 柴胡/半夏（浅山阴坡）
- **位置**：进山半天路程（4 TU）。
- **采集难度**：高，需辨认，有迷路和毒蛇风险。
- **价值**：中（王老大夫常年收购，可换 2–3 斗粮食）。

## 3. 猎物点（浅山）
- **资源**：野兔、山鸡。
- **危险**：野猪、狼（下山频率随冬季变高）。
- **归属**：无主，谁猎到归谁。

## 4. 渔点（镇前深潭）
- **产出**：杂鱼、河虾。
- **限制**：里正规定，汛期禁渔，平时任何人可钓。
