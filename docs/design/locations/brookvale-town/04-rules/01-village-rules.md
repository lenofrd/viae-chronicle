# 溪谷镇 - 村规与越轨判定映射

*系统核心引擎只处理越轨大类（见 `systems/agents/06-actions.md` §2.5：`steal_asset` / `violate_rule` / `assault` / `sacrilege`），本配置把具体行为映射到大类并给出严重度与惩罚。惩罚类型须取自 `systems/human-environment/07-conflicts/05-punishment.md` 的清单。*

## 1. 财产与资源类越轨
- **偷鸡摸狗**：
  - 动作映射：`steal_asset`
  - 目标：家禽。
  - 严重度 (Severity)：2。惩罚：批评（私下训诫）+ 赔粮。
- **偷牛**：
  - 动作映射：`steal_asset`
  - 目标：牛。
  - 严重度 (Severity)：10。惩罚：公开羞辱（祠堂公开杖责）+ 赔粮双倍。
- **私自截水（旱季）**：
  - 动作映射：`violate_rule`
  - 严重度 (Severity)：6。惩罚：限制权利（取消当月轮灌资格）+ 赔粮。

## 2. 暴力与人身类越轨
- **斗殴伤人**：
  - 动作映射：`assault`
  - 严重度：5。惩罚：赔粮（医药费）+ 赔礼（公开道歉）。
- **忤逆不孝（打骂父母）**：
  - 动作映射：`violate_rule`
  - 严重度：8。惩罚：公开羞辱（祠堂罚跪三天）+ 限制权利（宗族除名）。

## 3. 信仰与禁忌类越轨
- **砍伐神树**：
  - 动作映射：`sacrilege`
  - 严重度：12（最高级别）。惩罚：驱逐（全村排斥，逐出镇）。
