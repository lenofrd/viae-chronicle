# 溪谷镇 - 村规、土地治理与建造审批

*系统核心引擎只处理越轨大类（见 `systems/agents/06-actions.md` §2.5：`steal_asset` / `violate_rule` / `assault` / `sacrilege`），本地点文档把具体行为映射到大类并给出地方制度参数。土地权属和治理通用机制分别见 `systems/human-environment/02-institutions/07-land-tenure-and-use.md` 与 `08-village-governance.md`；自主建造见 `01-social-spaces/06-autonomous-construction.md`。*

## 1. 土地权属原则

溪谷镇采用家庭私有与集体共有并存的混合制度：

| 土地 | 初始权属原则 | 使用规则 |
|---|---|---|
| 宅基地 | 家庭所有 | 可依法继承、转让、出租 |
| 私有田地 | 家庭所有 | 耕种、出租和转让受水权与用途规则约束 |
| 集体田地 | 村落集体所有 | 分配或出租给家庭耕种 |
| 道路和巷道 | 集体 | 公共通行，不得私自阻断 |
| 水渠和取水设施 | 集体管理 | 按水权规则使用和维护 |
| 河岸 | 集体 | 捕鱼、渡运和通行按规约许可 |
| 山林 | 集体管理 | 依采集规则使用，采集权不等于所有权 |
| 公共设施用地 | 集体 | 用于公共设施和公共活动 |
| 神树保护地 | 集体保护 | 禁止普通私人开发 |
| 深山禁区 | 特殊保护 | 禁止常规建设和开发 |

宅基地家庭所有是已确认决策。家庭所有权仍受用途规划、建筑边界、安全要求、邻地权利和公共通行权约束。所有权、使用权、用益权、通行权、用途许可和管理权分开登记。

## 2. 用途管制

水浇田和坡旱地原则上维持农业用途。农田改住宅或作坊属于重大用途变更，须家庭代表议事会批准。河岸仅允许与捕鱼、渡运和公共通行相容的设施；私人经营须取得集体授权。山林采集权不等于开垦权。深山禁区、神树保护地和关键水源保护范围不得通过普通村庄审批开发。

## 3. 里正与家庭代表议事会

- 每个有效家庭一名成年代表，每户一票；初始 30 户对应 30 个席位。
- 里正由家庭代表推举，提交县级官府认可后就任。
- 任期三年，可以连任；每届期满必须重新推举和认可。
- 初始设一名副手，只在职位空缺时临时代理，不自动永久继任。
- 普通议题以有效票过半为门槛；重大土地用途变更、集体土地长期处分和重大公共建设以有效票三分之二为门槛。
- 里正涉及本人、家庭、亲属或共同经营者的直接利益时必须回避。
- 里正无权单方面改变集体决议、没收私人土地或改变保护地用途。
- 罢免、辞任、死亡、长期失能、迁出和官府撤销认可均须产生明确离任记录；副手仅临时代理。

候选资格、提名、首轮与复选、法定人数、官府认可和罢免程序遵循通用治理系统。地方初始化不得创造脱离居民历史的系统官员。

## 4. 建设类型与审批

| 项目 | 默认程序 |
|---|---|
| 屋顶、墙体、门窗等日常修缮 | 家庭自主，事后登记 |
| 自家宅基地内小型柴棚、储物棚 | 家庭自主，里正备案并检查边界 |
| 普通住宅新建或扩建 | 里正审批 |
| 鱼棚、晒网场、药材棚等小型生产设施 | 里正审批；占河岸或集体地另需集体授权 |
| 小型织布或加工棚 | 里正审批 |
| 规模较大的作坊、客舍 | 里正审查；有明显公共影响时提交议事会 |
| 占用集体土地 | 家庭代表议事会批准 |
| 农田、林地、河岸用途变更 | 家庭代表议事会批准 |
| 水井、桥、公共仓库等公共设施 | 家庭代表议事会决定 |
| 深山、神树保护地建设 | 普通审批禁止 |

个人和家庭均可发起私人项目。个人在家庭宅基地上建设须取得权利家庭授权；集体土地建设须先取得合法使用权。公共设施由集体提出并经议事程序决定。

## 5. 审查、申诉与复核

里正审查土地权利、用途、建筑 footprint 和面积、道路/水渠/河岸通行、邻地影响、灾害风险、审批层级和利益冲突。

审批结果为批准、附条件批准、暂缓并说明待补事项，或驳回并说明规则依据。不得仅以申请人贫富、声望或宗族身份作为审批理由。

家庭或个人不服里正日常审批，可向家庭代表议事会申请复核。议事会可维持、变更、撤销或发回重审；原审批人和有直接利益冲突的代表必须回避。复核期间，争议项目暂停新增占地和不可逆施工。议事会复核结果对村庄权限范围内的审批具有约束力，里正负责执行，不得自行推翻。超出村庄权限的事项仍须向县级官府申诉。

## 6. 开工条件与生命周期

审批通过后仍须满足：土地权利生效、用途合法、footprint 已预留、材料和劳动力来源明确、家庭能够承担成本，且必要的邻地、通行和水利安排已完成。材料、货币、工具和劳动力不得凭空生成；施工按 Tick 推进。

建筑生命周期包括使用、维护、修缮、扩建、改建、出租、转让、继承、受损、废弃和拆除。建筑废弃不自动导致土地权利消失。

## 7. 土地纠纷

常见纠纷包括宅基地边界不清、建筑越界或堵塞通道、河岸使用权冲突、水渠维护和通行权争议、继承人对宅基地分配意见不一、集体土地出租价格或期限争议。

里正可组织初步调解；涉及里正本人、亲属或其家庭利益时必须回避。审批申诉由家庭代表议事会复核。边界未厘清的争议地块暂停不可逆施工和转让。

## 8. 既有村规越轨映射

系统核心动作与惩罚类型见对应 systems 文档。本地点保留既有具体映射：

### 8.1 财产与资源类越轨

- 偷鸡摸狗：`steal_asset`，目标为家禽，严重度 2；私下训诫并赔粮。
- 偷牛：`steal_asset`，目标为牛，严重度 10；公开羞辱并双倍赔偿。
- 私自截水（旱季）：`violate_rule`，严重度 6；限制当月轮灌资格并赔偿。

### 8.2 暴力与人身类越轨

- 斗殴伤人：`assault`，严重度 5；赔偿医药费并公开道歉。
- 忤逆不孝（打骂父母）：`violate_rule`，严重度 8；依既有村规公开羞辱并限制相关权利。

### 8.3 信仰与禁忌类越轨

- 砍伐神树：`sacrilege`，严重度 12；触发最高级别地方惩戒。具体惩罚执行仍须遵循通用惩罚清单和程序。
