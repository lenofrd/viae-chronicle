# 溪古镇（Brookvale）- 家族与家庭结构

## 1. 林家（底层自耕农）
- **成员**：林远（核心）、陈氏（母亲）、林父（卧床不起，腿部残疾，几乎无行动能力）。
- **处境**：缺乏青壮年劳力。每年春耕和秋收都要靠“换工”求邻居帮忙，因此欠下了一些人情债。属于随时可能因一场病或灾荒跌落到贫户的家庭。

## 2. 赵家（婆家，镇上小富农）
- **成员**：赵大（死去的丈夫的哥哥）、赵大媳妇、以及两个游手好闲的儿子。
- **处境**：住在平民区东侧。他们一直觊觎赵翠兰那一亩水浇地，经常找借口上门闹事。
- **关系**：极度仇视赵翠兰。视林远家为路人。

## 3. 李家（权力中心）
- **成员**：李全（里正）、李妻（早逝，现由小妾管家）、李秀儿（女儿）。
- **处境**：家大业大，雇佣了 3 名长工。控制着水渠的阀门。
- **关系**：表面上对所有村民一视同仁，实际上极度护食。

## 4. 王大夫家（手艺人家）
- **成员**：王老大夫、他的老妻。
- **处境**：无子嗣，生活富足但常有孤独感。由于掌握医疗资源，镇上没人敢得罪他。

## 5. 婚姻、从夫居与家庭财产

本节定义溪古镇地方习俗；通用机制见 [人口承载与婚姻形成](../../../systems/society/agents/12-population-and-marriage.md)，决策依据见 [ADR 007](../../../decisions/007-population-and-marriage.md)。

### 5.1 从夫居

- 婚姻成立后，女方本人迁入男方家庭，成为家庭成员并参与家庭劳动与生活。
- 婚后出生的子女加入夫妻共同生活的家庭。
- 女方原家庭继续存在；不要求原家庭没有其他成年成员，也不因女方出嫁而解散。
- 女方此前已有子女不自动随迁，监护和迁移由相关家庭另行安排。

### 5.2 相识与婚姻候选

- 婚姻候选必须建立在双方真实相识基础上，初期读取人物系统现有的双向 `known` 认知。
- 近期互动记忆用于辅助判断交往经历和候选排序；认识不代表好感，更不代表同意结婚。
- 本地点不预设陌生人自动结婚；未来可以扩展媒人介绍、家庭议婚和感情培养，但不在本阶段增加复杂恋爱状态机。
- 既有初始关系（例如李秀儿与穷书生的隐秘私情）是开局背景，不直接等同于婚约或婚姻登记。

### 5.3 彩礼与陪嫁

- 男方家庭向女方原家庭支付彩礼。数额不设统一固定值，由双方家庭结合各自资源储备、债务、基本生活需求及劳动力变化衡量协商。
- 彩礼只能使用男方家庭实际持有的资源支付；支付后不得出现负库存，也不得无视基本食物安全储备。
- 女方原家庭自行决定是否提供陪嫁、提供何种财产及数量。陪嫁与彩礼是两笔独立转移，不互相默认抵扣。
- 女方本人迁入男方家庭，不意味着女方原家庭其他成员、资产、住所或债务自动转移。
- 未明确约定的财产留在原家庭；所有转移均须守恒并可 Replay。

### 5.4 地方参数边界

以下数值由后续模拟校准，不在本设计中预设：

- 双向认知的 TTL 和互动记忆参考窗口。
- 彩礼估值参考的家庭安全储备、债务压力和劳动力变化权重。
- 彩礼协商的让步幅度、等待时间与失败概率。
- 不同经济水平家庭可使用的礼物品种与支付组合。

## 6. 家庭共同生活、照料与分工（ADR 008）

### 6.1 家庭资源边界
- 家庭粮食、蔬菜、肉、鱼、布、水等库存归本户所有，由家庭成员共同生活使用；公共储备是独立集体库存。
- 当前家庭库存不设容量上限，也不因超量自动损耗、出售或转存；建筑储存容量接口暂不限制库存，未来可由地窖、粮窖、储物棚和扩建机制接入。
- 家庭库存超过任何安全天数都不会被系统自动转入公共储备。家庭成员可以自愿上交，但必须明确物资、数量和代表家庭的行为主体。
- 家庭不能直接把共享仓储中其他家庭的寄存余额当作自家或公共库存。

### 6.2 日常饮食
- 每日安排一顿以粮食等主食为基础的正餐；配餐按家庭库存、季节和生产情况安排。
- 蔬菜、肉、鱼不要求每顿都有，但家庭饮食应在滚动七日窗口内达到地点配置的基本摄入目标。
- 肉与鱼可按配置折算为动物性食物摄入；蔬菜另行统计。短期缺少配餐不立即造成健康损失，长期持续不足才影响健康。
- 家庭成员共同消费家庭库存，进食仍须扣除实际物资与所需用水。

### 6.3 家庭照料与代办
- 同住家庭成员并非彼此漠不关心。面对幼儿、老人、患病/受伤者或失能者，家庭成员会基于亲缘义务、关系、共同生活和现实能力考虑照料。
- 照料包括送食物、送水和模型已支持的基本护理；照料占用行动时间，不能无成本远程恢复。
- 户主失能或无法行动时，其他有能力的成员可以代表家庭向里正申请救济。
- 家庭成员关系疏远、发生冲突、能力不足或自身处于生存危机时，照料可能失败；不把亲缘义务写成百分之百成功的强制行为。
- 全家无人能行动时，允许邻里报告并由里正启动紧急核查，作为常规家庭代办之外的兜底。

### 6.4 家庭协商与分工
- 家庭根据当日粮水库存、田间季节任务、成员健康/年龄/技能/体力和可用 TU，协商安排取水、农耕、捕鱼/采集、织作、照料和求助。
- 分工应减少重复劳动和关键任务空缺；不要求所有成员从事相同劳动，也不把成员固定为单一职业。
- 家庭计划是协调建议而非户主命令。成员可因个人意愿、能力、路程、体力或突发事件拒绝、无法完成并触发重新安排。
- 现有家庭经济账户、田块分配和 Agent 独立行动继续保留；家庭协商不创建第二套家庭库存或个人行动系统。

### 6.5 里正与公共储备
- 家庭成员主动向里正提出粮食、饮水等物资申请；里正受理、核实并按议事会制定的公开规则组织发放。
- 里正负责日常管理和账目登记，议事会负责规则制定、监督和争议复核。初期里正可兼任仓储经办，但不得把公共储备视为私人财产。
- 公共储备只能由 Agent/家庭明确自愿上交形成；不得由系统按家庭安全线自动征收。发放必须真实扣减公共库存并记入家庭库存。
- 具体通用规则见 [ADR 008](../../../decisions/008-household-coordination-nutrition-and-voluntary-reserves.md)。
