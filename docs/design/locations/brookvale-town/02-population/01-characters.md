# 溪谷镇 - 初始人物名册

## 1. 核心主角（3人，精细模拟，提供深度经历）
主角是视角的焦点，他们的人生轨迹将展现小镇的阶级、性别和生存困境。

### 1.1 林远（男，18岁）
- **身份**：自耕农之子 / 准木匠学徒。
- **住所**：镇中平民区。
- **性格**：心气高，渴望向上流动。内心对深山的“仙人传说”有隐秘的向往，不甘心一辈子种地。
- **困境**：父亲早年在浅山摔断了腿，家中劳力不足。他极度想拜镇上的老木匠为师（向上通道），但母亲需要他留在田里。
- **初始资产**：西片田旱地两亩（吃力），祖传的一把破旧铁犁。
- **初始诉求 (Aspiration)**：学一门手艺，攒钱给家里买头牛。

### 1.2 赵翠兰（女，23岁）
- **身份**：寡妇。
- **住所**：镇西贫民区（茅草屋）。
- **性格**：坚韧、敏感，因常年受欺负而带有极强的防备心。
- **困境**：丈夫两年前去浅山采药失踪（实则被妖兽所害，但她不知）。婆家指责她“克夫”，经常上门抢粮。她独自抚养一个 2 岁的女儿，极度缺乏安全感。
- **初始资产**：东片田水浇地一亩（这是她最后的底线，常被婆家惦记），家禽两只。
- **初始诉求**：守住田产，让女儿吃饱。

### 1.3 李全（男，48岁）
- **身份**：里正 / 镇上首富。
- **住所**：富户区（高墙大院）。
- **性格**：精明、伪善。表面满口村规道义，实则利用水权分配和调解纠纷中饱私囊。
- **困境**：他想把女儿嫁给城里的货商，但女儿和镇上的穷书生有染（家族丑闻隐患）。同时，今年夏旱苗头已显，他需要压住村民对“水权分配”的质疑。
- **初始资产**：东片田好田二十亩，水牛两头，存粮百石。
- **初始诉求**：维持自己的面子，不让旱情演变成针对他的暴动。

## 2. 重要配角（5人，中度模拟，推动冲突与信息传播）
他们有自己的欲望，会在主角的关键抉择中起到助力或阻碍。

### 2.1 王老大夫（男，56岁）
- **职业**：镇上唯一的郎中，药铺老板。
- **设定**：早年曾在外游历，见过一点修仙界的皮毛，懂得处理外伤，但不肯对外透露。极度谨慎，害怕惹祸。对赵翠兰有几分同情，偶尔赊药给她。

### 2.2 赵老七（男，36岁）
- **职业**：游商 / 情报贩子。
- **设定**：每隔几月带些外界的盐、铁和新鲜消息回镇。滑头、好色。经常在言语上挑逗赵翠兰，是潜在的性骚扰源头。他带来外界的消息，也带走镇上的钱。

### 2.3 陈氏（女，52岁）
- **职业**：林远的母亲，典型的传统农妇。
- **设定**：身体不好，极度重视宗族规矩和传宗接代。她最大的愿望是逼林远赶紧娶个媳妇。对林远想学木匠的想法嗤之以鼻（觉得种地才是本分）。

### 2.4 张木匠（男，45岁）
- **职业**：镇上的老木匠。
- **设定**：手艺好，但脾气古怪、保守。他有“留一手”的习惯。他一直想收一个免费的苦力当学徒，但看林远家里缺劳力，故意开出高价拜师礼刁难。

### 2.5 李秀儿（女，16岁）
- **职业**：李全（里正）的独生女。
- **设定**：从小没吃过苦，天真浪漫。向往外头的世界，私下喜欢读书识字，与外界保持着一点隐秘的联系。
