# 溪谷镇 - 初始关系网络

在系统启动的第 0 天，角色之间已经存在复杂的历史纠葛。系统读取以下数据建立初始关系。

## 1. 信任与利益图谱
- **林远 ↔ 陈氏**：血缘母子。信任高，但在“学木匠还是种地”上存在理念冲突（易触发家庭争吵）。
- **林远 ↔ 张木匠**：林远对张木匠有敬意（信任+0.5），张木匠觉得林远是不错的苦力但不想白教（利益权重 0.3）。
- **赵翠兰 ↔ 赵大**：极度敌对。赵翠兰对赵大信任为 -0.9，且存在深仇大恨（Grudge）。赵大想夺取她的田地。
- **赵老七 ↔ 赵翠兰**：赵老七单方面骚扰。赵翠兰对赵老七信任 -0.5，极度厌恶。

## 2. 债务与人情网络
- **林家 ↔ 邻居周家**：林家去年春耕借了周家 2 个工，目前欠人情（Obligation = -2.0），尚未偿还。
- **赵翠兰 ↔ 王大夫**：赵翠兰因为女儿生病，欠了王大夫 1 斗米的药费（债务）。王大夫不催，但赵翠兰压力很大。
- **李全 ↔ 全体村民**：村民普遍对李全有轻微的敬畏和不满（信任 0.2，但利益冲突高），因为李全掌握水阀。

## 3. 潜在的情感与性张⼒
- **李秀儿 ↔ 穷书生**：隐秘的私情。李全（里正）尚未发觉，一旦发觉会立刻爆发家族危机。
- **林远 ↔ 赵翠兰**：目前是普通邻里。但因为两家都处于底层，未来可能在互助中产生同情或更复杂的情感（系统不预设，交给演化）。

## 4. 初始仇恨（Grudges）
- **赵翠兰 → 赵大**：强度 0.8。来源于婆家掠夺家产和辱骂。
- **林远 → 里正李全**：强度 0.4。因为李全分配水渠阀门时，总是让林家所在的西片田最后灌溉，导致减产。

## 5. 信息差（Information Asymmetry）
- 只有 **王老大夫** 和 **赵老七** 知道深山里有“修士”的真实存在。
- **赵老七** 知道外界城市的布价在跌，但他隐瞒了，准备在赶集时低价收村里的布。
- **陈氏** 知道张木匠早年有过一个私生子，这是她握着的把柄，但她不敢随便得罪手艺人。
