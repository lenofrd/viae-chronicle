# 溪谷镇土地分区与地块规划

> locations / xigu-town / geography  
> 通用规则：systems/human-environment/01-social-spaces/05-land-parcels-and-buildings.md

## 1. 地理布局

地图为 64 × 40 地形格。翠溪南北向流经地图西侧；河流东岸为农耕区和聚落区，聚落东侧依次为山脚林地、浅山密林和深山禁区。住宅、田地和主要聚落活动均位于河流同一岸。渡口是河岸交通节点，不代表住宅区跨河扩张。

## 2. 分区规则

| 分区 | 主要用途 | 可建设规则 |
|---|---|---|
| 河道 | 自然水体 | 禁止私人建筑 |
| 河岸 | 渡口、捕鱼、公共通行 | 仅允许许可的低影响设施 |
| 水浇田带 | 灌溉农田 | 原则上禁止住宅；变更须集体议事 |
| 坡旱地带 | 雨养农田、轮作 | 原则上保持农业用途 |
| 聚落核心 | 住宅、道路、集市、公共地标 | 依地块权属和规划建设 |
| 山脚林地 | 柴薪和日常采集 | 禁止随意转为住宅区 |
| 浅山密林 | 草药、硬木、猎物等 | 生产使用受资源规则限制；普通住宅原则上不进入 |
| 深山禁区 | 特殊生态和异象 | 禁止常规采集、道路和私人建设 |
| 神树保护地 | 神树古栎及周边 | 特殊保护，普通私人开发禁止 |

地理分区是用途审查基础，不代替具体地块产权和面积记录。

## 3. 地块划分

- 一块地可覆盖多个 TerrainCell。
- 宅基地按院落整体划分，住宅、柴棚和菜地可在同一地块内。
- 农田按可耕作边界和灌溉关系划分。
- 道路、水渠和公共通道作为线性空间或通行权登记。
- 河岸可划分公共使用区与经许可的专用使用区。
- 山林资源采集区不等于可私有化林地。
- 保护地不得被普通地块切分后规避保护规则。

## 4. 初始空间格局

- 河流位于地图西侧，住宅和田块均在东岸。
- 农耕活动集中在聚落西侧至中部之间。
- 聚落中心连接水井、集市、祠堂、里正家和药铺。
- 山脚林地与浅山采集区位于聚落东侧，深山禁区位于最东侧。
- 贫困家庭初始住宅偏南、靠近渡口但远离优质水浇田。
- 平民住宅靠近水井和集市。
- 富户住宅初始靠近灌溉取水和水浇田通路。

精确格子坐标由世界生成配置维护；本文规定空间关系，不把实现坐标写成永久制度。

## 5. 选址与发展空间

选址必须检查地块用途和权属、坡度排水、春汛淹没风险、滑坡野兽和火灾风险、道路饮水点和工作资源通行成本、对农田水渠河岸和邻地的影响，以及建筑 footprint、入口和扩建余量。

初始保留地分为家庭空置住宅槽位、集体预留地和生态保留地。空置住宅槽位不等于无主公共土地。聚落扩展优先使用合法预留地和低冲突地块，不允许无边界向农田、河岸和山林扩张。

## 6. 验收条件

1. 所有住宅与主要田地位于河流同一岸。
2. 深山禁区没有普通建设用地。
3. 神树保护范围不被住宅或作坊侵占。
4. 农田转住宅需要集体决议。
5. 道路、水渠和河岸通行权不会被私人建筑阻断。
6. 空置住宅槽位与可自由开发土地是两个不同概念。
