# 可逆性

## 1. 目的
定义状态变化分可逆、准不可逆、不可逆三类，各带不同的恢复条件和时间。所有状态变化必须标记可逆性类别。

## 2. 核心概念
- 可逆（reversible）：变化可以通过自然过程或人类行动恢复，恢复时间明确。
- 准不可逆（quasi-irreversible）：变化可以恢复，但需要极长时间（多年到数十年），在模拟时间尺度内近似不可逆。
- 不可逆（irreversible）：变化永久，无法恢复。
- 恢复条件：可逆变化必须声明恢复条件（如“采集压力降低后”“降雨恢复后”）。
- 恢复时间：可逆变化必须声明恢复时间范围。
- 不可逆标记：不可逆变化必须标记，并记录触发事件。

## 3. 声明格式
每个状态变化规则声明：
```
reversibility_class: reversible / quasi-irreversible / irreversible
recovery_condition: 可选，可逆时必填
recovery_time: 可选，可逆时必填
```

## 4. 演化规则

### 4.1 可逆变化恢复
```
条件：恢复条件满足
效果：状态按恢复速率向原值回归
      恢复速率通常慢于变化速率
      恢复到原值后停止
滞后：恢复时间由 recovery_time 声明
影响范围：按状态变量
```

### 4.2 准不可逆变化恢复
```
条件：恢复条件满足
效果：状态按极慢速率恢复
      恢复时间以年计
      模拟时间尺度内可能看不到完全恢复
滞后：极长
影响范围：按状态变量
```

### 4.3 不可逆变化
```
条件：不可逆变化发生
效果：状态永久改变，不提供恢复路径
      标记 irreversible = true
      记录触发事件
滞后：无
影响范围：按状态变量
```

### 4.4 不可逆变化清单
以下变化标记为不可逆或准不可逆，第一版按此执行：
| 变化 | 类别 | 说明 |
|---|---|---|
| 古树被砍 | 不可逆 | 无法再生 |
| 人员死亡 | 不可逆 | 无法恢复 |
| 山洪冲毁的当季作物 | 不可逆 | 当季无法恢复 |
| 滑坡改变坡面形态（陡坡→崖壁） | 不可逆 | 地形永久改变 |
| 河道严重淤积改变形态 | 不可逆 | base_capacity 永久降低 |
| 裸地恢复到阔叶林 | 准不可逆 | 需要数十年 |
| 地力严重退化 | 准不可逆 | 恢复上限降低 |
| 田埂冲毁 | 可逆 | 可修复，需人力 |
| 房屋损毁 | 可逆 | 可重建，需人力 |
| 山路中断 | 可逆 | 可修复，需人力 |
| 植被覆盖度下降 | 可逆 | 可恢复，需多年 |
| 资源存量耗尽 | 可逆 | 可恢复，需长时间 |

### 4.5 恢复与人物行动
```
条件：可逆变化的恢复依赖人物行动
效果：恢复条件包含“人物修复事件”
      如田埂修复需要人物写入 repair 事件
      无人修复则保持损坏状态
滞后：按修复事件
影响范围：按状态变量
```

## 5. 事件类型
- `state_recovered`：{unit_id, variable, old, new, cause}
- `irreversible_change`：{unit_id, variable, old, new, cause}
- `repair_completed`：{unit_id, damage_type, cause}

## 6. 与其他系统的接口
- 所有子系统的状态变化规则引用本机制，标记可逆性类别。
- 人物系统的修复行动（修渠、修路、重建）作为可逆变化的恢复条件。
- 记录系统在人生事件里标记不可逆变化，作为关键节点。

## 7. 地点参数占位
- 各类变化的 reversibility_class
- 可逆变化的 recovery_condition、recovery_time、recovery_rate
- 准不可逆变化的恢复上限
- 修复行动的人力成本和时间
