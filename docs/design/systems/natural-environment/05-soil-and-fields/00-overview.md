# 土壤与田地子系统总览

## 1. 目的
定义田地片作为空间单元的土壤湿度、地力、作物状态、病虫害如何随气候、灌溉、人类劳作变化，以及这些状态如何驱动收成和人物决策。

## 2. 核心概念
- 田地片：按片管理的生产单元，挂在空间骨架上，有位置、面积、水源条件。
- 土壤湿度：快变量，受降水和灌溉影响，影响作物长势。
- 地力：慢变量，按季累积变化，受连作、施肥、轮耕、休耕影响。
- 作物状态：每片田当前种什么、处于哪个生长期、长势如何、有无病虫害。
- 收成：作物成熟后的产出，受地力、湿度、病虫害、灾害共同影响。
- 病虫害：与季节、湿度、作物状态相关的风险，可触发虫害事件。

## 3. 状态变量（按田地片挂载）
| 变量 | 类型 | 说明 | 变化速率 |
|---|---|---|---|
| soil_moisture | float 0–1 | 土壤湿度 | 快变量，受降水和灌溉 |
| fertility | float 0–1 | 地力 | 慢变量，按季变化 |
| crop_type | enum? | 当前作物（无/稻/麦/麻/菜等） | 按季切换 |
| growth_stage | enum | 播种/发芽/生长/抽穗/成熟/收割/休耕 | 按作物周期 |
| growth_health | float 0–1 | 长势健康度 | 受湿度、地力、病虫害影响 |
| pest_risk | float 0–1 | 病虫害风险 | 随季节和湿度累积 |
| irrigation_state | enum | 充足/偏少/缺水/断水 | 从水文系统读取 |
| expected_yield | float | 预期收成（派生量） | 随状态变化 |

## 4. 演化规则分类
- tick 驱动：土壤湿度随蒸发和作物耗水下降、地力按季缓慢变化、作物按生长期推进。
- 事件驱动：降水补充湿度、灌溉事件、施肥事件、虫害爆发、收割事件。
- 累积效应：连作导致地力下降、长期不施肥导致地力退化、过度灌溉导致盐碱化（第一版不做）。
- 外部注入：接口写入的田地事件（如人为破坏、外来种子），标注为外部事件。

## 5. 事件类型
- `soil_moisture_changed`：{field_id, old, new, cause}
- `fertility_changed`：{field_id, old, new, cause}
- `crop_planted`：{field_id, crop_type, cause}
- `growth_stage_changed`：{field_id, old, new}
- `growth_health_changed`：{field_id, old, new, cause}
- `pest_risk_changed`：{field_id, old, new, cause}
- `pest_outbreak`：{field_id, severity, affected_area}
- `harvested`：{field_id, crop_type, yield_amount, quality, cause}
- `field_damaged`：{field_id, damage_type, severity, cause}（如山洪冲毁、滑坡掩埋）

## 6. 与其他系统的接口
- 读：
  - 02-climate：降水、温度、季节系数、极端天气（霜冻、酷热）。
  - 03-hydrology：灌溉条件、水位。
  - 04-terrain：坡度、坡向、滑坡后果。
  - 08-hazards：山洪冲毁田地、旱降低地力、虫害降低收成。
  - 人物系统：播种、施肥、灌溉、收割、休耕等劳作事件。
- 写：
  - 人物系统：提供田地状态和预期收成，作为决策输入（种什么、何时收割、是否改种）。
  - 08-hazards：提供虫害风险和灾害后的田地损毁状态。
  - 记录系统：收成事件作为人物一生的关键节点。
- 因果链：旱季水位下降 → 灌溉缺水 → 土壤湿度下降 → 作物长势变差 → 预期收成下降 → 人物决策（争水、改种、借粮）。

## 7. 地点参数占位
具体地点（如 Brookvale）需要提供：
- 田地片清单：ID、名称、位置（近河/远河、上游/下游）、面积、依赖的取水点
- 各田地片的初始地力、土壤湿度
- 作物清单：类型、生长周期、适宜季节、需水量、对地力的消耗和恢复
- 地力变化速率、连作惩罚、施肥恢复量、休耕恢复速率
- 土壤湿度变化速率、蒸发系数、作物耗水系数
- 病虫害触发条件、爆发概率、影响系数
- 收成计算公式的参数（地力、湿度、健康度、灾害的权重）

## 8. 扩展预留
- 新作物：在 crops.md 里扩展，通过配置声明生长周期和需求。
- 新田地类型（如水田、旱地、梯田）：作为田地片属性扩展。
- 土壤类型（黏土/沙土/壤土）：第一版不做，预留属性位。
- 盐碱化、水土流失：作为地力退化的扩展机制，第一版不做。
- 轮作制度：作为人物系统的规则，田地子系统只提供地力消耗和恢复的基础数据。
