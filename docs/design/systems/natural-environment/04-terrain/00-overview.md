# 地形子系统总览

## 1. 目的
定义山脚、浅山、深山三层空间单元的结构和可达性梯度，定义坡面朝向对资源、温度、湿度的影响，定义滑坡风险点的触发条件和后果。

## 2. 核心概念
- 山层：山脚、浅山、深山，代表可达性和风险梯度。
- 坡面：阳坡/阴坡，影响日照、湿度、植被、积雪。
- 坡度：缓坡/陡坡/崖壁，影响通行、耕作、滑坡。
- 滑坡风险点：特定坡面，暴雨后触发概率上升。
- 山路：连接山层和资源点的路径，可被滑坡或塌方中断。

## 3. 状态变量（按山层/坡面挂载）
| 变量 | 类型 | 说明 | 变化速率 |
|---|---|---|---|
| soil_stability | float 0–1 | 土体稳定度（派生量，由 06 的 vegetation_cover 和 04 的 soil_saturation 计算，不单独维护） | 受植被和降雨影响 |
| landslide_risk | float 0–1 | 滑坡风险 | 随降雨累积上升，随干燥下降 |
| trail_state | enum | 山路通行状态：畅通/受损/中断 | 事件驱动 |

各状态变量的 `max_delta_per_tick` 见地点参数。

## 4. 演化规则分类
- tick 驱动：植被覆盖按季缓慢变化、土体稳定度缓慢恢复、积雪随季节消融。
- 事件驱动：暴雨触发滑坡风险上升、滑坡发生、山路中断。
- 累积效应：过度砍伐降低植被覆盖 → 土体稳定度下降 → 滑坡风险上升。
- 外部注入：接口写入的地形事件（如山体崩塌），标注为外部事件。

## 5. 事件类型
- `landslide_risk_changed`：{unit_id, old, new, cause}
- `landslide_occurred`：{unit_id, severity, affected_units}
- `trail_state_changed`：{trail_id, old, new, cause}

## 6. 与其他系统的接口
- 读：02-climate 的暴雨、温度、季节；06-vegetation 的植被覆盖；08-hazards：山洪/滑坡事件改变山路状态、坡面形态；人物系统的砍伐、开垦事件。
- 写：02-distance-and-time 读山路状态和坡度，修正通行时间；06-vegetation 读坡向和坡度，影响资源分布；08-hazards 读滑坡风险，触发滑坡事件。
- 记录系统：滑坡、山路中断作为人物通行受阻和心理变化的父事件。
- 因果链：暴雨 → 滑坡风险上升 → 滑坡发生 → 山路中断 → 人物通行受阻 → 心理和决策变化。

## 7. 地点参数占位
- 山层清单：ID、名称、depth、elevation_range、terrain_risk
- 坡面清单：ID、所属山层、朝向（阳/阴）、坡度
- 滑坡风险点清单：ID、所属坡面、基础风险、触发阈值
- 山路清单：ID、连接的两个单元、基础通行时间
- 植被覆盖初始值、土体稳定度初始值、积雪季节性曲线
- 滑坡触发阈值、恢复速率、山路修复时间

## 8. 扩展预留
- 新山层：在 mountain-layers.md 扩展，通过配置声明。
- 新地形类型（如峡谷、崖壁）：作为新单元类型扩展。
- 矿山/采石场：作为资源点扩展，挂在山层下。
- 地震：作为新灾害类型，第一版不做，预留事件类型。
- 积雪覆盖：第一版不做，作为扩展预留。

## 9. 横切机制引用
