# 交互动力学与习惯化

## 1. 目的
定义长期的交互历史如何反过来影响未来的会话。人与人的交涉不是每次都在白纸上重新开始，而是带着默契、习惯或创伤。

## 2. 核心概念
- **习惯化（Habituation）**：双方如果就同类话题反复交涉并达成共识，后续的交涉轮数会大幅减少，甚至直接跳过试探。
- **信任修复（Trust Repair）**：如果曾发生破裂或背叛，关系不会自然恢复。下一次会话的“信任门槛”会极高，必须有补偿动作才能重启。
- **沟通默契**：关系强度（strength）高的双方，信息不对称的门槛降低，能听懂对方的潜台词。

## 3. 演化规则

### 3.1 默契形成
```
条件：双方就同类话题（如换工、借小物件）成功达成协议 N 次
效果：标记 relation.habituation = true
      后续同类会话的最大轮数强制减半（甚至直接 1 轮同意）
      生成 habituation_formed 事件
滞后：长期过程
影响范围：特定关系边
```

### 3.2 信任破裂与修复
```
条件：发生过严重的谈判破裂或违约
效果：标记 relation.broken_trust = true
      后续任何交涉，初始 Resistance 增加巨额惩罚
      必须通过“补偿”或“第三方调解”动作，才能消除 broken_trust 标记
滞后：按事件
影响范围：特定关系边
```

### 3.3 情绪记忆
```
条件：在上次会话中被对方“情绪化攻击”（如道德绑架、公开羞辱）
效果：本次会话中，接收方初始的 emotion_score 显著偏高
      更容易触发 [拒绝] 或 [情绪化] 选项
滞后：按事件
影响范围：特定关系边
```
