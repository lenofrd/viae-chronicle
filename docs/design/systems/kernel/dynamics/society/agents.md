# 人物演化机制

## 1. 目的
定义人物状态的通用变化机制（习惯化、疲劳积累、衰老、观念演变）。

## 2. 核心概念
- **习惯化**：同一种刺激反复出现，心理波动递减。
- **疲劳积累**：长期不休息，体力上限下降。
- **衰老**：年龄增长导致体力上限下降。
- **性别观念漂移**：在长期冲击或代际更替下，社区的性别规范可能缓慢变化。

## 3. 规则
- 衰老：每年结算，体力上限 -1%，健康恢复速度 -1%。
- 习惯化：同类负面事件连续发生，stress 增加量每次衰减 10%。
- 观念漂移：若某一性别角色成功打破了规范（如女性行医救人），社区的 gender_norms 会发生极缓慢的偏移，后续执行该动作的 norm_penalty 降低。

## 4. 横切引用
- 上述变化速率（衰老、习惯化、观念漂移）均遵循全局 `09-dynamics/` 规则：渐进、不瞬移、可有滞后。
