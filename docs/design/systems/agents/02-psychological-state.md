# 心理状态

## 1. 目的
定义人物的情绪、压力、动机优先级，以及“性别角色内化”带来的心理冲突。

## 2. 核心概念
- **压力（stress）**：受饥饿、冲突、灾害、债务影响。
- **恐惧（fear）**：受野兽、灾害、强权影响。
- **角色冲突压力（role_conflict_pressure）**：当个人意愿（aspiration）与社会性别期望不符时产生的内耗。
- **情绪效价（valence）**：近期总体开心/沮丧程度（-1 到 1）。

## 3. 状态变量
| 变量 | 类型 | 说明 |
|---|---|---|
| stress | float 0–100 | 总体压力 |
| fear | float 0–100 | 恐惧 |
| valence | float -1–1 | 情绪效价 |
| role_conflict_pressure | float 0–100 | 性别角色冲突压力 |

## 4. 演化规则

### 4.1 压力累积与释放
```
条件：遭遇负面事件
效果：stress += 事件严重度
      获得正面事件时 stress -= 缓解量
```

### 4.2 性别角色冲突
```
条件：角色试图执行违背社会性别期望的行动（如女性想进深山采药，男性想学织布）
效果：role_conflict_pressure += 违背程度
      若 role_conflict_pressure > 阈值：
        可能放弃行动（压力过大）
        或强行执行，并承受额外的 stress（叛逆代价）
```

### 4.3 心理防御与极端反应
```
条件：长期高压或高角色冲突
效果：可能形成执念（如拼命想证明自己）或认命（放弃 aspiration）
      影响 05-decision-making 中的效用评分
```

## 5. 与其他系统的接口
- 读：人物记忆、制度约束、社区舆论。
- 写：决策系统（影响主观重要性和风险判断）、多轮交互（影响情绪回应）。
- 被写：交互系统（interaction）的交涉过程可修改 stress 与 valence——谈判破裂、违约、被羞辱加压；达成协议、获得补偿降压或提升 valence。
