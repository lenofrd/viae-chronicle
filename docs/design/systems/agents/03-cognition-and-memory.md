# 认知与记忆

## 1. 目的
定义人物知道什么、记得谁、对环境的判断，以及对“男女该做什么”的内化认知。

## 2. 核心概念
- **知识库**：人物掌握的信息（来自 04-information）。
- **关系记忆**：对周围人的主观印象（信任、恩怨）。
- **空间记忆**：知道哪里有水、哪里能砍柴。
- **性别规范认知（gender_norms）**：内化的“什么性别该做什么事”的认知。
- **认知偏差**：允许误判（如高估风险、记错恩怨）。

## 3. 状态变量
| 变量 | 类型 | 说明 |
|---|---|---|
| knowledge_set | set | 人物掌握的信息条目（来自 04-information） |
| beliefs | dict | 对事物的主观信念（可与事实不符） |
| gender_norms | dict | 内化的性别规范，决定“哪些行动适合我做” |
| relation_memory | dict | 对周围人的印象（信任、恩怨强度） |
| spatial_memory | dict | 对资源点与地点的记忆（水源、柴薪位置等） |

## 4. 演化规则

### 4.1 记忆强化与遗忘
```
条件：事件发生或被提及
效果：相关的记忆强度增加
      长期不提及，记忆强度缓慢衰减
```

### 4.2 性别规范习得
```
条件：家庭教养（05-education）、社区规训
效果：内化社会对性别的期望
      gender_norms 决定角色认为“哪些行动适合我做”
      如：女性内化“主内”，男性内化“主外”
```

### 4.3 认知更新与冲突
```
条件：接收新信息
效果：更新知识库和关系记忆
      若新信息与旧认知（尤其是性别规范）冲突，生成 cognitive_dissonance 事件，推高角色冲突压力
```

## 5. 与其他系统的接口
- 读：人文环境 04-information、05-education。
- 写：决策系统（提供“我以为”的主观世界和性别预期）。
