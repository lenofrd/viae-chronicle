# 需求与效用

## 1. 目的
定义人物如何评估需求，以及如何对候选行动打分（效用函数）。这是纯规则决策的核心。

## 2. 核心概念
- **需求层次**（第一版简化）：生存（吃饱） > 安全（避灾） > 经济（积累财富） > 社交（维持关系）。
- **主观重要性**：结合需求层次、性格、当前心理状态计算出的权重。
- **效用打分（Utility）**：满足的需求减去消耗的资源、体力，再减去社会规范惩罚。

## 3. 状态变量
| 变量 | 类型 | 说明 |
|---|---|---|
| current_needs | dict | 当前各需求的紧缺程度 |
| utility_scores | dict | 候选行动的效用打分（决策时计算） |
| norm_penalty | float | 某行动违背内化性别规范的惩罚（0 表示符合规范） |

## 4. 演化规则

### 4.1 需求权重计算
```
条件：每 tick
效果：weight(need) = 基础权重 * (1 + 紧缺程度) * 心理修正
```

### 4.2 行动效用打分
```
条件：决策时
效果：score(action) = sum(weight(need) * fulfill(action, need))
                    - cost(action)
                    - risk(action) * (1 + fear)
                    - norm_penalty(action)
```

### 4.3 社会规范惩罚（norm_penalty）
```
条件：评估某个行动
效果：若 action 违背内化的性别规范（gender_norms）：
        norm_penalty = 基础惩罚 * (1 + 角色冲突压力)
      违背程度越高，惩罚越大
      这会导致角色倾向于选择“符合规范”的行动
```

## 5. 与其他系统的接口
- 读：生理、心理、认知状态。
- 写：决策系统（提供排序后的行动列表）。
