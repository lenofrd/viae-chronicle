# 居民自主建造

> systems / human-environment / social-spaces：通用机制；地点提供建筑配方、许可阈值和资源条件。

## 1. 原则与发起主体

个人和家庭可基于需求、资源、劳动力和土地条件自主提出建造项目。集体公共建设由公共需求触发并经家庭代表议事决定。

个人若要在家庭所有宅基地上施工，须获得权利家庭授权；个人可通过购买、租赁或集体许可取得独立建设用地。发起项目不代表绕过土地所有者或审批程序。

## 2. 需求产生

需求可来自居住容量不足、家庭分家、生产效率受限、物资缺乏储存空间、收入稳定后出现投资机会、原建筑损坏或家庭财富技能劳动力允许改善条件。

需求强度受预期收益、成本、风险、债务、家庭目标和替代方案影响。并非每户都必须建造。

## 3. 建筑范围

第一阶段：住宅（草屋、木屋、院落住宅、扩建）、生产附属建筑（鱼棚、晒网场、柴棚、药材棚、储物棚）、小型作坊（织布棚、加工棚）。

后续扩展：小铺、仓房、客舍，以及水井、桥梁、公共仓库、祠堂和庙宇等公共设施。

## 4. 选址约束

硬约束：
- 申请人拥有或取得合法土地使用权。
- 土地用途允许该建筑，或用途变更已获批准。
- 可建设面积足够。
- footprint 不重叠、不占道路水渠或第三方通行权。
- 不在禁建保护地或不可接受风险区。
- 建筑入口可合法连接道路或通道。

软偏好：
- 到住宅、工作资源、道路和市场的通勤成本。
- 地势、排水、日照和取水便利。
- 邻里关系和潜在冲突。
- 土地价格、租金和未来扩建空间。
- 资源点和环境风险。

硬约束不能被高收益评分抵消。无合适土地时，居民可等待、租地、购买、合建、迁居或放弃。

## 5. 审批分级

| 建设行为 | 默认处理 |
|---|---|
| 既有建筑日常修缮 | 家庭自主，登记 |
| 自家宅基地内低影响附属棚屋 | 家庭自主，里正备案并检查边界 |
| 规划内普通住宅、小型作坊 | 里正审批 |
| 重大经营建筑或显著邻里影响 | 里正审查后提交议事会 |
| 占用集体土地、改变农田/林地/河岸用途 | 家庭代表议事会 |
| 公共设施 | 家庭代表议事会 |
| 保护地和禁建地 | 普通审批禁止 |

审批状态包括 draft、submitted、under_review、pending_council、approved、conditionally_approved、rejected、appealed、withdrawn、expired。每个决定需有理由、审批者、回避记录、依据规则和申诉路径。

## 6. 生命周期

需求形成 → 评估资产材料劳动力和收益 → 搜索候选地块 → 取得土地权利 → 提交申请并审批 → 预留 footprint → 筹集材料工具和劳动力 → 开工并按 tick 推进 → 完工登记 → 使用、维护、扩建、转让、继承或废弃。

项目取消、审批失效或长期停工时，按规则释放预留土地并处理已投入材料。

## 7. 材料、劳动和施工

材料不得凭空生成。配方由地点配置定义，可包括木材、茅草、柴草、石料、泥土、绳索、工具和货币。

劳动力来源：家庭成员自建、亲族邻里互助换工、雇佣居民并支付工钱、多户合建并约定产权和维护责任。

施工按阶段消耗材料与劳动时间。天气、疾病、灾害、工具损坏和材料短缺可以暂停或降低进度。已消耗资源必须有对应事件和资产变化。

审批通过后为 footprint 建立临时预留。预留不等于产权转移；取消或过期后解除；施工不得擅自扩大 footprint；边界争议或风险变化可触发暂停和复审。

## 8. 建筑生命周期与事件

建成后的建筑支持使用、维护、修缮、扩建、改建、出租、转让、继承、受损、停用、废弃、拆除和材料回收。建筑废弃不自动使地块无主。

事件包括 construction_intent_created、construction_application_submitted、construction_application_approved、construction_application_rejected、construction_application_appealed、construction_site_reserved、construction_started、construction_material_delivered、construction_progressed、construction_paused、construction_resumed、building_completed、building_maintained、building_expanded、building_transferred、building_inherited、building_abandoned、building_demolished、construction_site_released。

## 9. 验收条件

1. 居民可自主产生建设需求，但不保证需求都能实现。
2. 未取得土地权利的项目不能开工。
3. 项目不能超出可建设面积或占用保护地。
4. 并发项目不能重复预留同一 footprint。
5. 材料、货币和劳动力消耗守恒。
6. 审批申诉可以改变或撤销审批状态。
7. 建筑生命周期和土地权利分离。
8. 所有关键状态可通过事件 Replay。
