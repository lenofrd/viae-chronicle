# 土地权属与用途制度

> systems / human-environment / institutions：通用机制；地点参数放在 locations。

## 1. 目标与原则

定义土地权利、用途管制、取得与转移，以及这些权利如何约束居民行动。本文件不定义具体地图坐标，也不负责建筑施工。

- 土地是有限资源，不因居民需求而生成。
- 所有权、使用权、用益权、通行权和用途许可相互独立。
- 拥有土地不代表可以任意改变用途。
- 私人权利受既有道路、水利、邻地权利、公共规划和保护规则约束。
- 权利变化必须有可追溯的事件和依据。

## 2. 权利模型

| 权利 | 含义 |
|---|---|
| 所有权 | 土地归属主体 |
| 使用权 | 在约定期限或条件下使用土地 |
| 用益权 | 从土地取得特定收益，如依规采集 |
| 通行权 | 穿越或进入土地的合法权利 |
| 用途许可 | 允许土地用于何种活动 |
| 管理权 | 对共有土地执行维护和分配规则 |

不得只用一个 owner 字段表达全部关系。

权利主体包括 household、individual、community、shared_group 和 public_authority。个人在家庭所有宅基地上建设须取得权利家庭授权；集体持有公共土地和集体资源；县级官府仅在制度授权时介入。

## 3. 通用用途分类

residential（住宅院落）、farmland_irrigated（水浇田）、farmland_dry（坡旱地）、woodland（林地）、riverbank（河岸）、road（道路通道）、public（公共设施用地）、commercial（经营用地）、reserved（预留地）、protected（保护地）、vacant（待进一步审查的未分配土地）。

vacant 不等于可自由建设，仍需检查权属、规划、地形风险和公共约束。

## 4. 土地取得与权利变更

土地权利可通过初始配置、集体分配、买卖、赠与、继承、租赁、多户共有、集体临时许可或纠纷裁决取得。

溪古镇权限规则（见 ADR 005）：新宅基地分配、私人土地所有权转让/变更、农田/林地/河岸等规划用途变更，以及集体土地分配、长期出租、收回和重大处分，均须家庭代表议事会审核批准。继承依既有继承规则确认，但必须登记权属变更。土地权利登记和资料核验由里正日常办理，不等于里正有权单独批准上述处分。

每次变更记录地块、原/新权利主体、权利类型、有效期、对价或依据、批准主体、见证人和前置事件。租赁不改变所有权；临时许可不自动产生永久产权；土地交易不得消除道路、水渠、公共通行权或保护约束。

## 5. 用途变更与权利优先级

用途变更分为同一用途内调整、低影响用途调整、重大用途变更和禁止变更。重大变更包括农田改住宅、林地开垦、河岸改经营用地，应提交家庭代表议事。深山禁区、神树保护地、关键河道和不可建设风险区不得通过普通审批改变用途。

冲突时优先级：
1. 不可建设与安全保护规则。
2. 已登记的第三方所有权、使用权和通行权。
3. 集体公共设施及已生效公共规划。
4. 地块用途和建筑密度限制。
5. 私人权利人的建设偏好。

私人产权不能覆盖更高优先级的既有权利和保护规则。公共决议也不能无程序没收私人土地；征用须有明确授权、补偿和申诉记录。

## 6. 交易、继承与家庭变化

- 买卖：双方确认、权利审查、登记后生效。
- 继承：依地点习俗和家庭关系确定继承人；有争议时标记权利待定。
- 分家：不自动把宅基地切成多个地块；检查面积、通道和建筑安全。
- 出租：明确期限、租金、维护义务和用途。
- 债务处置：第一阶段只记录债权和处分限制，不默认债权人自动取得土地。
- 建筑废弃不等于土地无主，须经继承、转让、收回或裁定处理。

## 7. 状态与事件

权利记录至少包含 tenure_id、parcel_id、holder_type、holder_id、right_type、valid_from_tick、valid_until_tick、conditions、source_event_id、status。

核心事件：land_right_granted、land_right_transferred、land_right_leased、land_right_inherited、land_right_revoked、land_use_changed、land_access_right_granted、land_right_disputed、land_right_confirmed。

事件记录前后状态、行为主体、目标地块、依据和因果父事件。土地制度读取地块、地形风险、家庭资产和治理决议；向选址、审批、纠纷、交易和继承提供约束，不直接修改地形、资源存量或施工进度。

## 8. 验收条件

1. 同一地块可有不同类型的合法权利，但不能有冲突的排他所有权。
2. 租赁不会改变所有权。
3. 建筑废弃不会自动释放土地权利。
4. 私人产权不能绕过保护地和既有通行权。
5. 分家不会自动产生超出实际面积的宅基地。
6. 每次权利变化均可从事件流重建。
