# 主观重要性与节奏

## 1. 目的
定义“主观重要性”如何决定一次会话的轮数、耗时，以及纠结局（反复无常）的发生概率。

## 2. 核心概念
- **主观重要性（Subjective Importance）**：双方对此次议题觉得有多重要。
- **重要性公式**：重要性 = 利益相关度 + 不可逆性 + 信息掌握度 + 情绪放大。
- **节奏（Pacing）**：低重要性的交涉快刀斩乱麻；高重要性的交涉反复拉锯。

## 3. 演化规则

### 3.1 重要性评估
```
条件：会话开启时
效果：计算双方的 importance 评分（0–1）
      生成 session_importance_evaluated 事件
```

### 3.2 决定最大轮数
```
条件：根据 importance
效果：importance < 0.3（低）：max_rounds = 1–2
      0.3 <= importance < 0.7（中）：max_rounds = 3–5
      importance >= 0.7（高）：max_rounds = 6–10
```

### 3.3 纠结局
```
条件：importance 高，且出现了双方都无法退让的核心条件（如地界、嫁娶）
效果：生成 prolonged_deadlock 事件
      会话停滞，可能需要引入第三方（调解人）或跨多个 tick 进行。
```

### 3.4 误判与代价
```
条件：发起方低估了接收方的重要性评估（以为对方不在乎，其实踩了雷区）
效果：接收方产生高额的 Resentment（怨恨）和压力，直接中断会话或后续报复。
```
