# 山层定义

## 1. 目的
定义山脚、浅山、深山三层作为空间单元的结构、可达性梯度、资源特征和风险等级。

## 2. 核心概念
- 山脚：日常可达，资源有限，风险低。
- 浅山：半天往返，资源中等，有迷路和野兽风险。
- 深山：一天以上，稀缺资源，高风险，第一版不开放精细移动。
- 可达性梯度：越深入，时间成本、体力消耗、风险都上升。
- 资源梯度：越深入，资源越稀缺、再生越慢。

## 3. 山层字段
| 字段 | 类型 | 说明 |
|---|---|---|
| layer_id | string | 如 `mountain-foot`、`mountain-shallow`、`mountain-deep` |
| name | string | 显示名 |
| depth | enum | foot / shallow / deep |
| elevation_range | string | 相对海拔描述 |
| travel_time_from_town | string | 从镇域出发的单程时间 |
| terrain_risk | enum | 低/中/高 |
| resource_points | list | 挂载的资源点 ID |
| trails | list | 连接本层的山路 ID |
| state | dict | 植被覆盖、土体稳定度、滑坡风险等 |

## 4. 可达性梯度规则
- 山脚：从镇域出发不到半天，体力消耗低，风险低，可当天往返。
- 浅山：从山脚出发半天，体力消耗中，有迷路、蛇虫、野兽风险，需结伴。
- 深山：从浅山出发一天以上，体力消耗高，有滑坡、瘴气、大型野兽、外人痕迹，第一版只作为事件源，不开放精细移动。

## 5. 资源梯度规则
- 山脚：柴薪、常见草药、放牧，再生快（周/月），采集压力高时退化明显。
- 浅山：特定草药、木材、猎物，再生中（季），采集难度中。
- 深山：稀缺药材、大兽、石料，再生慢（年），采集难度高，风险高。

## 6. 山层生命周期
- 山层由地点配置创建，第一版不动态增删。
- 山层状态由本子系统和其他子系统更新。
- 扩展预留：允许“山体崩塌”事件临时改变某层可达性，但不删除山层。

## 7. 事件类型
- `layer_accessibility_changed`：{layer_id, old, new, cause}

## 8. 与其他系统的接口
- 02-distance-and-time 读 `travel_time_from_town` 和 `terrain_risk` 计算移动成本。
- 06-vegetation 读山层和坡面，决定资源分布。
- 07-fauna 读山层深度，决定危险动物出没概率。
- 08-hazards 读山层和滑坡风险，触发滑坡和野兽下山。

## 9. 地点参数占位
- 三层山层的 ID、名称、elevation_range、travel_time_from_town、terrain_risk
- 每层挂载的资源点清单
- 每层的初始植被覆盖、土体稳定度
