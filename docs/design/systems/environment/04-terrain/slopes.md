# 坡面定义

## 1. 目的
定义坡面朝向和坡度如何影响日照、温度、湿度、植被、通行、滑坡风险。

## 2. 核心概念
- 坡向：阳坡（南向，日照多，干燥）、阴坡（北向，日照少，湿润）。
- 坡度：缓坡（可耕作、易通行）、陡坡（可采集、通行慢）、崖壁（不可通行、易崩塌）。
- 坡面是山层的子单元，一个山层可包含多个坡面。

## 3. 坡面字段
| 字段 | 类型 | 说明 |
|---|---|---|
| slope_id | string | 唯一 ID |
| parent_layer | string | 所属山层 ID |
| aspect | enum | 阳坡/阴坡 |
| gradient | enum | 缓坡/陡坡/崖壁 |
| vegetation_type | string | 植被类型（如灌木、针叶林、草坡） |
| state | dict | 植被覆盖、土体稳定度、滑坡风险等 |

## 4. 演化规则
坡向对温度的影响：阳坡温度高于阴坡，冬季积雪融化快，春季返青早。
坡向对湿度的影响：阴坡湿度高于阳坡，喜湿草药多分布阴坡。
坡度对通行的影响：缓坡可正常通行，陡坡通行时间加倍，崖壁不可通行。
坡度对植被的影响：缓坡土层厚，可长乔木；陡坡土层薄，多灌木和草；崖壁几乎无植被。
坡度对滑坡的影响：陡坡土体稳定度低，暴雨后滑坡风险高；缓坡稳定度高。

这些影响不单独产生事件，而是作为修正系数被其他子系统读取。

## 5. 坡面生命周期
- 坡面由地点配置创建。
- 坡面状态由本子系统和 06-vegetation 更新。
- 扩展预留：允许“坡面崩塌”事件改变坡度（陡坡→崖壁），不可逆。

## 6. 事件类型
- `slope_gradient_changed`：{slope_id, old, new, cause}（不可逆事件，如崩塌）

## 7. 与其他系统的接口
- 06-vegetation 读坡向和坡度，决定植被类型和资源分布。
- 02-distance-and-time 读坡度，修正通行时间。
- 08-hazards 读坡度和坡向，计算滑坡风险。
- 02-climate 读坡向，修正局部温度和积雪。

## 8. 地点参数占位
- 坡面清单：ID、所属山层、aspect、gradient、vegetation_type
- 坡向对温度/湿度的修正系数
- 坡度对通行时间、植被、滑坡的修正系数
