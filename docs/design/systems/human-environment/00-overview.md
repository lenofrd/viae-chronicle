# 人文环境总览

## 1. 目的

人文环境子系统负责定义 Brookvale 小镇的**人文侧**：建筑与场所的社会意义、制度规则、关系网络、信息环境、教育机制、阶层与流动、冲突与惩罚、仪式与信仰。它回答三个问题：

- 人生活在什么样的规则和关系里？（当下快照）
- 这些规则和关系怎么变成现在这样？（演化历史）
- 规则和关系接下来会怎么变？（演化规则）

人文环境不是自然环境的附属，它有自己的演化节律。自然环境回答“世界允许什么”，人文环境回答“人允许什么、人期待什么、人害怕什么”。

## 2. 设计原则

**2.1 人文先于个体**
制度、关系、信息、教育先于单个角色存在并演化。角色出生时，规则已经在了，关系网已经在了，传闻已经在了。角色只能学习、适应、有限改变，不能凭空设定。

**2.2 五条现实性**
所有人文变量受五条约束：

- **因果链**：制度变化、关系变化、谣言传播、舆论形成都要有前因事件，不能凭空发生（外部注入要标注为外部事件）。
- **时间尺度**：关系变化是渐进的；谣言传播需要人际接触，不是瞬间全镇皆知；制度不会因一次纠纷就改。
- **空间差异**：同一件事，在祠堂前和在田埂上影响不同；上游人家和下游人家对水权的感受不同。
- **滞后与累积**：一次背叛信任大降，但一次帮忙不会立刻恢复；舆论形成需要多人议论、多次事件累积。
- **可逆/不可逆**：关系可修复但需要时间；制度可改但需要反复冲突；有些伤害（如公开羞辱）可能终身影响地位。

**2.3 历史与快照并存**
每个人文要素同时存两样东西：

- **演化历史（事件流）**：回答“为什么现在是这个样子”。
- **当下快照（社会状态）**：回答“此刻规则是什么、谁和谁什么关系、谁在传什么话”。

两条线缺一不可。只有历史没有快照，人物行动没有规则依据；只有快照没有历史，记录失去因果。

**2.4 信息不对称是常态**
不同角色知道的事不一样。谁知道水渠要修、谁知道谁家借粮不还、谁知道山神禁忌的来历——信息分布不均匀，是拉扯和冲突的重要来源。

**2.5 教育是总机制，不是独立系统**
教育不只是一条“识字/上学/学手艺”的窄路。家庭教养、生计技能、社区规训、仪式信仰、信息经验、代际传递——这些都是人文环境塑造人的过程。教育嵌在日常生活里，不单独做一个“教育系统”。

**2.6 冲突是规则的显影剂**
制度平时是背景，冲突发生时才被看见、被引用、被挑战、被修改。冲突不是异常，是人文环境演化的正常机制。

## 3. 空间骨架

人文环境沿用自然环境的空间单元，但赋予它们**社会意义**：

**3.1 建筑节点**
祠堂、磨坊、水井、私塾、药铺、里正家、山神庙、集市空地、住家片区。每个建筑有功能、状态、在场人物、正在发生的事。建筑不只是“功能点”，它自带人文意义和冲突潜力——祠堂前被罚过的人，路过时心理状态不一样。

**3.2 公共空间与私人空间**
- **公共空间**：祠堂、水井、集市空地、山神庙。信息在这里流动，舆论在这里形成，规则在这里被公开执行。
- **私人空间**：住家、私家田地、私家作坊。信息在这里被保守，关系在这里被私下经营。
- **半公共空间**：磨坊、药铺、私塾。有门槛，但不是完全私密，信息在这里被选择性传播。

**3.3 场所的社会意义**
每个场所不只是物理位置，它规定了“在这里什么行为合适、什么话能说、什么人在场”。祠堂前适合公开议事和惩罚，水井边适合闲聊和传谣，田埂上适合私下交涉。人物行动时，场所的社会意义影响 ta 的选择。

## 4. 子系统依赖图

人文环境各子系统之间的读写关系：

```text
社会空间 (01)
  ├─ 提供 → 制度 (02)：场所是制度执行的物理依托
  ├─ 提供 → 关系 (03)：场所是关系发生的地点
  ├─ 提供 → 信息 (04)：公共空间是信息流动的通道
  └─ 提供 → 仪式 (08)：祠堂、山神庙是仪式的场所

制度 (02)
  ├─ 驱动 → 冲突 (07)：制度被违反或挑战时触发冲突
  ├─ 驱动 → 教育 (05)：社区规训传递制度
  ├─ 驱动 → 阶层 (06)：制度定义地位和流动通道
  └─ 驱动 → 关系 (03)：制度影响关系中的权利和义务

关系 (03)
  ├─ 驱动 → 冲突 (07)：关系恶化触发冲突
  ├─ 驱动 → 信息 (04)：信任关系决定信息传播路径
  └─ 驱动 → 教育 (05)：家庭和师徒关系是教育的主要通道

信息 (04)
  ├─ 驱动 → 冲突 (07)：谣言和传闻可以激化冲突
  ├─ 驱动 → 关系 (03)：信息影响信任和判断
  └─ 驱动 → 阶层 (06)：信息优势影响地位

教育 (05)
  ├─ 驱动 → 阶层 (06)：教育是向上流动的主要通道
  ├─ 驱动 → 关系 (03)：共同学习经历形成关系
  └─ 驱动 → 仪式 (08)：教育传递信仰和禁忌

阶层 (06)
  ├─ 驱动 → 冲突 (07)：阶层差异和流动受阻触发冲突
  └─ 驱动 → 关系 (03)：阶层影响关系中的权力不对等

冲突 (07)
  └─ 反馈 → 所有子系统：冲突改变制度、关系、信息、阶层

仪式与信仰 (08)
  ├─ 驱动 → 教育 (05)：仪式是教育的一部分
  ├─ 驱动 → 关系 (03)：共同仪式强化关系
  └─ 驱动 → 制度 (02)：禁忌和信仰支撑制度合法性

演化机制 (09) 和 状态与记录 (10) 是横切层，被所有子系统引用。
```

**依赖原则**：上游子系统只提供状态和事件，不直接修改下游子系统；下游子系统读取上游状态，按自己的规则演化。冲突（07）是反馈节点，它的后果广播回所有子系统。

## 5. 与自然环境的关系

人文环境和自然环境是**双向耦合**，不是单向依赖：

**人文环境读自然环境：**
- 水位、地力、灾害后果作为制度触发、关系变化、冲突爆发的输入。
- 例：旱季水位下降 → 水权制度被触发 → 上游和下游人家冲突 → 关系恶化。

**人文环境写自然环境（通过人物系统）：**
- 人的行动改变自然环境：砍柴、捕猎、修渠、开垦。
- 人文环境不直接改自然环境，人的行动通过人物系统写入自然事件。

**共享机制：**
- 两者共享 `09-dynamics` 的通用演化机制（变化速率、滞后累积、空间传播、可逆性）。
- 两者共享 `10-state-and-records` 的记录格式（事件流、快照、查询接口）。
- 人物事件同时属于人文环境和自然环境的因果链：一个人砍柴是人文事件（生计技能、资源分配），也是自然事件（植被退化、柴薪存量下降）。

## 6. 演化机制（四种驱动源）

**6.1 tick 驱动（慢变量）**
关系随日常互动缓慢变化、信息在人际网络中缓慢传播、制度在反复冲突中缓慢松动。按日/季推进，不依赖重大事件。

**6.2 事件驱动（快变量）**
一次背叛、一次公开惩罚、一次谣言爆发、一次水权纠纷。有触发条件和因果前因，触发条件依赖关系状态、信息分布、制度约束。

**6.3 累积效应（涌现）**
多次小冲突累积成制度变迁、多次小帮忙累积成信任、多人议论累积成舆论。不是谁“决定”的，是聚合出来的。

**6.4 外部注入**
从接口写入的人文事件（如“颁布新规”“外来消息”），标注为外部事件，同样进入事件流，同样受五条现实性约束。

详细机制见 `09-dynamics/`。

## 7. 状态与记录的通用约定

**7.1 人文状态**
每个人文要素有当前状态快照：
- 制度：当前规则、执行状态、被挑战次数。
- 关系：两个角色之间的信任、利益权重、关系类型。
- 信息：谁知道什么、信息在谁之间传播、传闻的可信度。
- 阶层：每个角色的地位、角色、流动意图。
- 仪式：当前节庆状态、禁忌遵守情况。

**7.2 事件流**
每个人文变化是一个事件，带统一 payload：

```text
tick, location_id, actor_id, target_id, variable, old_value, new_value,
cause_event_id, effect_scope, reversible, recovery_time
```

人文事件和自然事件共享同一因果链。水权纠纷是事件，它同时改变关系状态、触发制度执行、成为后续人物心理迁移的父事件。

**7.3 查询组合**
- 查某人一生：事件流每条带当时的人文快照摘要（关系状态、制度约束、信息掌握）。
- 查某个关系：返回关系演化历史 + 当前快照。
- 查某个制度：返回制度被引用、被违反、被挑战的历史。

详细字段规范见 `10-state-and-records/`。

## 8. 第一版范围

**做：**
- Brookvale 镇域 5–10 个建筑节点的人文属性，公共/私人/半公共空间区分。
- 制度：水权轮灌、地界、禁伐禁猎、村规、互助换工、祭祀禁忌。
- 关系：亲缘、邻里、债务、恩怨、信任和利益权重。
- 信息：知识分布、谣言传播、收成传闻、山神传说、外来消息。
- 教育：家庭教养、生计技能、社区规训、仪式信仰、信息经验、代际传递。
- 阶层：地位、角色、向上通道、向外的接口（只记录意图和镇内结果）。
- 冲突：水权纠纷、地界冲突、债务纠纷、违反村规的惩罚。
- 仪式：祭祖、祭山神、节庆、婚丧嫁娶、禁忌认知。

**不做（预留接口）：**
- 跨镇/跨城的人文网络。
- 制度的形式化法律体系（第一版只有村规和习俗）。
- 复杂的舆论模型（第一版只做“多人议论 → 舆论形成”的简化版）。
- 向外的实际离开（只记录意图和尝试，不执行离开）。
- 阶层的大规模流动（第一版只做镇内有限流动）。

## 9. 扩展预留

- **新地点**：`systems/` 只写通用机制，具体地点的制度、关系、信息参数放 `locations/<地点>/human-params.md`。加城市时新建 location，通用机制不动。
- **新子系统**：作为新文件夹加入 `systems/human-environment/`，在依赖图里声明读写关系。
- **新驱动源**：在 `09-dynamics/` 里新增驱动类型，现有子系统通过配置引用。
- **新事件类型**：各子系统在自己的文档里声明，`10-state-and-records/` 的通用 payload 结构不变。
- **LLM 接入**：作为旁路进程读事件流、写叙事文本，不改变人文环境的状态模型和演化规则。
- **跨世界迁移**：角色从一个世界迁移到另一个世界时，人文状态（关系、信息、地位）需要显式映射，第一版不做。

## 11. 横切机制引用

- 变化速率上限、滞后与累积、空间传播、可逆性规则见 `09-dynamics/`。
