# 村庄治理、里正与家庭代表议事

> systems / human-environment / institutions：通用机制；具体人口、资格和行政背景由 location 配置。

## 1. 初始制度

溪谷镇采用：**乡里推举、官府认可、家庭议事监督**。这是本项目的模拟制度设定，不宣称是所有历史时期统一存在的制度。

## 2. 治理主体

**家庭代表议事会**
- 每个有效户籍家庭一名代表，由家庭内部推举。
- 代表须为成年家庭成员，户主不必然担任代表。
- 家庭分立并完成登记后取得独立席位；合户后席位合并。
- 财富、土地面积和宗族规模不直接增加票数。
- 暂无合资格成年成员的家庭可委托表达意见，但不产生额外票数。

议事会决定重大公共事项、集体土地、公共建设、里正选任监督和审批复核。

**里正**
日常行政执行者和公共事务协调者，负责户籍与家庭登记、土地权利登记、日常建设审批、会议召集、公共事务协调、初步调解和执行有效决议。里正不是土地所有者，也没有凌驾于议事会之上的无限权力。

**副手**
初始一人，协助登记、会议记录、审批材料和公共事务。副手不是自动继任者；职位空缺时只可临时代理。

**县级官府**
村庄之外的认可与监督主体。第一阶段可作为外部制度接口，不要求模拟完整县衙人口和流程。认可、驳回或撤销必须记录理由。

## 3. 候选人资格与推举

候选人最低资格由地点配置，例如成年、稳定居住、有基本公共事务处理能力。不得将富有、地主身份或特定宗族身份设为硬性资格。

候选人可有 administration（行政能力）、mediation（调解能力）、integrity（廉洁倾向）、prestige（声望）、influence（影响力）、health（健康）等属性。这些属性影响居民判断，不直接决定当选。

流程：
1. 职位空缺或任期届满，启动推举。
2. 家庭提名候选人，允许合资格者自荐。
3. 核验资格、利益冲突和履职记录。
4. 家庭代表讨论和表决。
5. 推举结果提交县级官府。
6. 官府认可后就任；不认可须记录理由并重新提名或复议。
7. 任职开始和结束均写入事件流。

建议初始门槛：首轮有效票三分之二；无人达到时，得票前两名进入第二轮，第二轮过半数。法定人数建议为总席位三分之二；弃权不计入有效票分母。这些是可配置的模拟参数。

## 4. 任期与离任

溪谷镇已确认规则：
- 任期三年。
- 可以连任，不设固定连任次数上限。
- 每届期满必须重新推举并重新取得官府认可，不自动续任。
- 主动辞任、死亡、长期失能、迁出或罢免可提前离任。
- 空缺时副手临时代理；代理仅处理登记、紧急维护和已批准事务，不得自行决定重大用途变更或新增长期公共义务。
- 临时代理不得无限期延长。

任期按世界逻辑时间计算，三年对应地点日历中的三个完整年。

## 5. 权限分级

| 事项 | 权限 |
|---|---|
| 常规户籍、分户和迁居登记 | 里正 |
| 土地权利登记和资料核验 | 里正；权利争议另行处理 |
| 既有建筑日常修缮 | 家庭自主、里正备案 |
| 规划内小型建筑 | 里正审批 |
| 重大建筑、集体土地占用 | 家庭代表议事会 |
| 农田、林地、河岸重大用途变更 | 家庭代表议事会 |
| 公共设施和集体资金建设 | 家庭代表议事会 |
| 深山、神树等特殊保护地 | 普通村庄审批无权批准 |
| 超出村庄权限的事项 | 县级官府 |

里正不得单方面改变集体决议、没收私人土地、批准自身家庭利益申请或将保护地转为普通建设用地。

## 6. 议事与表决

议事会记录议题、提案人、受影响家庭、利益冲突、代表意见、表决和执行责任人。

建议门槛：普通事项有效票过半数；重大土地用途变更、集体土地长期处分、重大公共建设有效票三分之二；里正罢免有效票三分之二并提交县级官府确认。

代表依据家庭利益、邻里影响、宗族关系、公共收益、风险认知和信任形成意见。允许支持、反对、弃权、附条件支持和要求暂缓。议事会可批准、附条件批准、驳回或暂缓提案。

## 7. 回避、监督与申诉

里正、副手或代表涉及本人、配偶、直系亲属或共同经营家庭的直接利益时，应申报并回避相关审查或表决。回避人员可陈述事实，但不得主持或表决。

里正决定必须留有理由和依据。家庭代表可查阅公共决议相关登记；私人家庭信息按访问规则保护。贪腐、偏袒、拖延和失职可以发生，但必须由具体事件、关系和利益驱动，不能纯随机扣减声望。

家庭或个人不服里正日常审批，可向家庭代表议事会申请复核：
1. 提交原决定、争议理由和证据。
2. 检查是否属于村庄权限。
3. 有直接利益冲突的代表回避。
4. 审查土地权利、规划、公共影响和原审批程序。
5. 作出维持、变更、撤销或发回重审的决议。
6. 记录理由并通知相关主体。

复核期间，争议建设默认暂停新增占地和不可逆施工。议事会复核是村内程序；超出村庄权限或涉及县级官府决定的事项仍须向有权机关申诉。

## 8. 状态、事件与失败

状态包括 VillageOffice（职位与任期）、CouncilSeat（家庭代表席位）、LeadershipElection（提名、投票和官府认可）、CouncilMeeting（议题和决议）、GovernanceCase（审批、申诉、回避和裁决）。

核心事件：village_leader_nominated、village_leadership_vote_cast、village_leader_elected、village_leader_recognized、village_leader_recognition_rejected、village_leader_term_started、village_leader_resigned、village_leader_removed、village_leader_term_ended、deputy_appointed、council_meeting_convened、council_resolution_passed、official_recusal_recorded、permit_appeal_submitted、permit_appeal_reviewed。

系统允许无人愿意担任、票数接近、官府不认可、代表缺席、审批积压和宗族分裂。可延期、重新提名、临时代理、补充证据或上报官府，不得自动消除僵局。

## 9. 验收条件

1. 里正经过乡里推举和官府认可两步。
2. 三年任期届满必须重新推举，允许连任。
3. 副手只能临时代理，不能自动继任。
4. 每个有效家庭只有一个议事席位。
5. 里正不得审批自身直接利益事项。
6. 家庭可向议事会申诉，复核可维持、变更、撤销或发回重审。
7. 议事、选任、认可和申诉过程均可 Replay。
