# 制度子系统总览

## 1. 目的
定义 Brookvale 小镇的制度规则：水权轮灌、地界、禁伐禁猎、村规、互助换工、祭祀禁忌。制度规定“什么能做、什么不能做、违反了怎么罚、谁有权执行”。制度平时是背景，冲突时被引用、被挑战、被修改。

## 2. 核心概念
- **制度规则**：成文或不成文的行为规范，有适用对象、条件、后果。
- **制度状态**：当前规则内容、执行状态、被挑战次数、松动程度。
- **执行者**：谁有权执行规则（里正、长老、祠堂议事、村民集体）。
- **违反与惩罚**：违反规则触发惩罚事件，惩罚公开或私下执行。
- **制度变迁**：制度不会因一次纠纷就改，要反复冲突、有人推动、有人反对才可能松动。
- **制度与场所**：制度在特定场所执行（祠堂议事、里正家调解、水渠边争执）。

## 3. 制度清单与触发源
| 制度 | 核心冲突源 | 执行者 | 执行场所 |
|---|---|---|---|
| 水权轮灌 | 旱季水少、上游截水 | 里正/长老/轮灌约定 | 水渠边/里正家 |
| 地界 | 田埂越界、地界模糊 | 里正/地契/见证人 | 田埂/里正家 |
| 禁伐禁猎 | 过度砍伐、盗猎 | 村规/护林人/村民监督 | 山林/祠堂 |
| 村规 | 偷盗、伤人、通奸、不孝 | 里正/祠堂议事 | 祠堂 |
| 互助换工 | 农忙缺劳力、修渠出工 | 约定/人情/里正协调 | 田间/里正家 |
| 祭祀禁忌 | 冒犯山神、破坏神树 | 长老/祭司/舆论 | 山神庙/祠堂 |

## 4. 状态变量（按制度挂载）
| 变量 | 类型 | 说明 | 变化速率 |
|---|---|---|---|
| rule_content | dict | 当前规则内容（条件、允许、禁止、后果） | 事件驱动，慢变 |
| enforcement_state | enum | 严格执行/宽松执行/名存实亡 | 事件驱动 |
| challenge_count | int | 被挑战次数 | 累积 |
| looseness | float 0–1 | 松动程度 | 慢变，累积 |
| last_enforced_tick | int? | 上次执行 tick | 事件驱动 |
| violators | list | 近期违反者记录 | 事件驱动 |

## 5. 演化规则分类
- tick 驱动：looseness 缓慢变化（长期无人违反则趋稳，频繁违反则上升）。
- 事件驱动：违反、执行、挑战、修改。
- 累积效应：多次违反 → looseness 上升 → 制度松动 → 可能被修改。
- 外部注入：接口写入的制度事件（如“外来官员颁布新规”），标注为外部事件。

## 6. 事件类型
- `rule_violated`：{rule_id, violator_id, violation_type, severity, witnesses}
- `rule_enforced`：{rule_id, violator_id, enforcer_id, punishment, location}
- `rule_challenged`：{rule_id, challenger_id, reason, outcome}
- `rule_modified`：{rule_id, old_content, new_content, cause}
- `enforcement_state_changed`：{rule_id, old, new, cause}

## 7. 与其他系统的接口
- 读：
  - 01-social-spaces：制度在特定场所执行。
  - 03-relationships：关系状态影响制度执行（人情包庇、恩怨加重惩罚）。
  - 04-information：信息传播影响违规是否被发现。
  - 自然环境：`03-hydrology` 水位、`05-soil-and-fields` 地力、`08-hazards` 灾害触发制度执行（旱季水权、灾害后修渠）。
  - 07-conflicts：冲突结果强化或松动制度。
  - 08-rituals-beliefs：仪式支撑禁忌和制度合法性。
- 写：
  - 07-conflicts：制度被违反或挑战时触发冲突。
  - 05-education：社区规训传递制度。
  - 06-stratification：制度定义地位和流动通道。
  - 03-relationships：制度执行影响关系（惩罚、包庇、结怨）。
  - 人物系统：提供规则约束，作为决策输入。
- 因果链：旱季水位下降 → 水权制度被触发 → 上游截水违反规则 → 下游发现 → 争执 → 里正调解 → 惩罚或包庇 → 关系变化 → 制度松动或强化。

## 8. 地点参数占位
具体地点（如 Brookvale）需要提供：
- 各制度的具体规则内容（条件、允许、禁止、后果）
- 执行者清单和权限
- 执行场所
- 违反的严重程度分级
- 惩罚方式和力度
- 初始 looseness 和 enforcement_state
- 制度修改的触发条件（多少次挑战、多少人支持）

## 9. 扩展预留
- 新制度（如税收、兵役、市场规则）：作为新文件扩展。
- 制度的形式化（成文法）：第一版只有村规和习俗，预留成文法扩展。
- 跨镇制度（如县域法规）：作为多地点扩展，第一版不做。
- 制度冲突（两套规则并存）：作为扩展，第一版不做。
