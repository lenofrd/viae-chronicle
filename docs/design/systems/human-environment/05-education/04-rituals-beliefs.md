# 仪式信仰教育

## 1. 目的
定义仪式和信仰如何塑造角色的世界观、禁忌认知、敬畏心理。仪式不是娱乐，是教育：它传递“什么神圣、什么不能碰、人和自然是什么关系”。

## 2. 核心概念
- **仪式类型**：祭山神、祭祖、节庆、婚丧、求雨、驱邪。
- **仪式参与**：角色在仪式中的角色（主持、参与、旁观、缺席）。
- **信仰传递**：仪式通过重复、庄严、集体参与，强化世界观和禁忌。
- **敬畏心理**：仪式激发敬畏、恐惧、安慰，影响心理状态。
- **禁忌内化**：仪式让人内化“什么不能碰”。
- **代际传递**：长辈带晚辈参加仪式，传递信仰。
- **仪式与自然环境**：山神仪式与山林、河流、灾害绑定。

## 3. 仪式参与字段
| 字段 | 类型 | 说明 |
|---|---|---|
| ritual_id | string | 仪式 ID |
| ritual_type | enum | 祭山神/祭祖/节庆/婚丧/求雨/驱邪 |
| agent_id | string | 参与者 |
| role | enum | 主持/参与/旁观/缺席 |
| belief_effect | dict | 对世界观、禁忌认知、敬畏心理的影响 |
| internalization | float 0–1 | 内化程度 |

## 4. 演化规则

### 4.1 仪式参与
```
条件：仪式举行，角色参与
效果：角色获得信仰教育
      世界观、禁忌认知、敬畏心理变化
      生成 ritual_participation 事件
滞后：按仪式周期
影响范围：参与者
```

### 4.2 角色分工
```
条件：仪式中角色不同
效果：主持者内化最深（需要理解和传达）
      参与者内化中等
      旁观者内化较浅
      缺席者无直接内化，但可能被议论
      生成 role_effect_changed 事件
滞后：按仪式
影响范围：参与者
```

### 4.3 敬畏心理
```
条件：仪式庄严、灾害后仪式、长辈讲述
效果：敬畏心理上升
      影响禁忌遵守和心理状态
      生成 awe_effect 事件
滞后：按仪式
影响范围：参与者
```

### 4.4 禁忌内化
```
条件：反复参与仪式、长辈教导
效果：禁忌内化程度上升
      以后自觉遵守禁忌
      生成 taboo_internalization_changed 事件
滞后：长期过程
影响范围：参与者
```

### 4.5 代际传递
```
条件：长辈带晚辈参加仪式
效果：晚辈获得信仰教育
      代际传递信仰
      生成 ritual_participation（role = 旁观/参与）
滞后：按仪式周期
影响范围：晚辈
```

### 4.6 仪式与自然灾害
```
条件：灾害后举行仪式（求雨、驱邪、谢山神）
效果：仪式强化信仰
      灾害被解释为“山神发怒”或“惩罚”
      生成 ritual_participation（ritual_type = 求雨/驱邪）
滞后：灾害后
影响范围：社区
```

## 5. 事件类型
- `ritual_participation`：{agent_id, ritual_id, role, belief_effect, internalization}
- `awe_effect`：{agent_id, ritual_id, effect, severity}
- `taboo_internalization_changed`：{agent_id, taboo_id, old, new, cause}
