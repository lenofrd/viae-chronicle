# 家庭教养

## 1. 目的
定义家庭如何塑造子女的价值观、性别角色、辈分规矩、生存态度。家庭教养是最早、最日常的教育，多数时候不是正式教导，而是耳濡目染。

## 2. 核心概念
- **教养者**：父母、祖辈、兄姐。
- **教养内容**：价值观（勤劳、节俭、孝顺、诚实）、性别角色（男耕女织、男主外女主内）、辈分规矩（尊敬长辈、服从家长）、生存态度（谨慎、冒险、依赖、自立）。
- **教养方式**：言传、身教、奖惩、讲故事、日常示范。
- **教养结果**：子女内化部分价值观，抗拒部分，形成自己的判断。
- **教养冲突**：父母之间教养观念不一致、代际观念冲突。

## 3. 教养事件字段
| 字段 | 类型 | 说明 |
|---|---|---|
| upbringing_id | string | 唯一 ID |
| child_id | string | 受教子女 |
| caregiver_id | string | 教养者 |
| content | enum | 价值观/性别角色/辈分规矩/生存态度 |
| method | enum | 言传/身教/奖惩/讲故事/示范 |
| outcome | enum | 接受/部分接受/抗拒/反感 |
| internalization | float 0–1 | 内化程度 |

## 4. 演化规则

### 4.1 日常示范
```
条件：子女在场，父母处理日常事务（劳作、纠纷、待人接物）
效果：子女观察并模仿
      价值观和生存态度缓慢变化
      生成 upbringing_event（method = 示范）
滞后：长期过程
影响范围：子女
```

### 4.2 言传教导
```
条件：父母明确教导（“做人要勤劳”“见了长辈要问好”）
效果：子女接收教导
      outcome 受子女当前价值观和关系影响
      接受则 internalization 上升
      抗拒则可能反感
      生成 upbringing_event（method = 言传）
滞后：单次教导变化有限
影响范围：子女
```

### 4.3 奖惩
```
条件：子女行为符合/违反家长期望
效果：奖励 → 行为强化，internalization 上升
      惩罚 → 行为抑制，可能内化也可能反感
      生成 upbringing_event（method = 奖惩）
滞后：按奖惩时机
影响范围：子女
```

### 4.4 讲故事
```
条件：长辈讲述祖先故事、山神传说、生活经验
效果：子女获得世界观、禁忌认知、生存经验
      生成 upbringing_event（method = 讲故事）
滞后：长期过程
影响范围：子女
```

### 4.5 教养冲突
```
条件：父母教养观念不一致，或子女抗拒
效果：子女可能形成矛盾价值观
      家庭关系紧张
      生成 upbringing_conflict 事件
滞后：长期过程
影响范围：家庭
```

### 4.6 教养结果
```
条件：子女成年
效果：形成相对稳定的价值观、性别角色、辈分观念、生存态度
      部分内化，部分抗拒
      教养线记录在 education_history
滞后：成年时
影响范围：子女
```

## 5. 事件类型
- `upbringing_event`：{child_id, caregiver_id, content, method, outcome, internalization}
- `upbringing_conflict`：{child_id, caregivers, conflict_area}

## 6. 与其他系统的接口
- 读：03-kinship 的家庭关系；08-rituals-beliefs 的故事内容；04-information 的经验知识。
- 写：人物系统的价值观、性别角色、辈分观念、生存态度；06-stratification 的初始地位观念；05-education/06-generational-transfer 的代际传递。
- 因果链：父亲勤劳示范 → 子女内化勤劳 → 成年后勤劳 → 收成好 → 地位上升。
