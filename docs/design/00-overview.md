# Vale Chronicle — Design Summary

## 一、总体定位

你要做的不是游戏，而是一个**常驻运行的纯文字小镇模拟器**。

小镇里有一批人，按规则自主生活、互动、拉扯、成长。系统持续记录每个人的完整一生。你从外部程序随时读取任何人的经历，也能临时附身某个人替 ta 做选择，松手后 ta 继续自主生活。

核心产品是两样：**个体人生档案** + **读写接口**。

不是画面、不是玩家界面、不是剧情脚本。是“世界自己跑，人生可追溯，外部可读写”。

---

## 二、世界的基本形态

一个封闭但真实的小镇，**在山脚下，旁边有宽河和大片田地，周围是大山**。

空间不用连续地图，用**拓扑节点 + 距离/时间成本**表达现实尺度。

**小镇内部**：有名字、有位置、有功能、有状态的建筑节点，不是抽象格子。至少包括祠堂、磨坊、水井/渡口、私塾/账房、郎中家/药铺、里正家/村公所、山神庙/土地庙、集市空地、住家片区。每个建筑带功能、状态（坏了要修、缺药要采）、在场人物、正在发生的事。

**田地**：按片管理，有远近、地力、水源、作物状态。远田和近田的劳作成本不同。

**河流**：按河段划分，有水位、流速、可渡性、灌溉取水点。河宽体现为绕行远、渡河有风险、汛期不可过。上游和下游的利益不一致。

**山**：分层——山脚、浅山、深山。山脚日常可达但资源有限；浅山半天往返，有迷路和野兽风险；深山一天以上，有稀缺资源但高风险。山“很大”体现为进去一趟耗时久、危险高，而不是画很多格子。

**资源点具体到位置**：草药不是“山里有”，而是“浅山阴坡有柴胡”“深山溪谷有石斛”“河边湿地有芦苇根”“田埂地头有车前草”。每种资源有位置、再生速度、采集难度、危险性。

人物日常在这几块之间短途移动，当天往返。移动记录“去了哪、为什么去、走了多久、遇到什么”，不记录连续坐标。人物行动绑定具体场景锚点：“他站在田埂东段上，看着上游来水，对邻居说……”，而不是“他在坐标 (x,y) 执行 action_047”。

## 三、环境最重要：自然 + 人文

你明确认为**环境最重要**，第一版先把自然环境和人文环境做好，人物和交互围绕环境驱动。

### 1. 自然环境：会自己变、会逼人做选择

- **季节与气候**：春耕、夏汛、秋收、冬藏；雨季旱季交替，影响水位、地力、作物、山路通行。
- **河流**：水位随季节涨落；汛期危险、旱期水少；灌溉、饮水、捕鱼都依赖它。河是用水冲突的源头。
- **山林**：近山资源日常可达但有限；浅山有风险；深山有稀缺资源但高风险。砍伐和捕猎有再生速度，过度使用会退化。
- **田地**：每片有地力、水源、作物状态，受季节和灾害影响。
- **灾害与突变**：山洪、旱、虫害、滑坡、野兽下山、火灾。按事件触发，改变环境状态，也改变人的处境。
- **累积效应**：过度砍伐/捕猎导致资源退化；修渠、轮耕、造林可以恢复。

自然环境按自己的节律演化，不等人来感知才变。

### 2. 人文环境：规则、关系、信息

- **制度规则**：水权轮灌、地界、禁伐/禁猎、村规、互助换工、祭祀禁忌。这些是人物交互的规则来源。
- **关系网络**：亲缘、邻里、债务、恩怨。关系有信任和利益权重，随事件变化。
- **信息环境**：谁知道什么、谣言怎么传、收成传闻、山神传说、外来消息（第一版可以极少）。信息不对称是拉扯的重要来源。

### 3. 两者怎么耦合

自然环境产生事件（旱、汛、野兽、资源退化）→ 人文环境决定谁能感知、怎么解读、按什么规则响应 → 人物决策行动 → 行动累积又改变自然环境。

**环境是主语，人是谓语。** 先把这条闭环跑通。

## 四、环境变化要像现实一样

“与现实一样”不是复刻现实，而是让变化有前因、有速率、有滞后、有空间差异、有不可逆性。具体落到五条：

**1. 时间尺度真实**：季节不跳变；旱情积累若干天才成灾；山洪需要前期降雨累积加短时暴雨触发；地力恢复以年计；技能成长以月/年计。禁止“今天状态 A、明天状态 B”的瞬移式变化，所有环境变量有变化速率上限。

**2. 因果链真实**：上游截水 → 下游水量减少 → 下游稻田缺水 → 下游人家找上游理论。每一步都有事件，不能直接“下游生气了”。每个环境变化都要有前因事件，不能凭空发生（外部注入要标注为外部事件）。

**3. 滞后与累积真实**：今天砍十棵树，山林不会明天退化；连续砍一个月，近山资源明显变少。今天施肥，地力下一季才见效。今天修渠，水流通畅要几天后才稳定；渠道淤积慢慢积累，某天一场大雨才暴露问题。环境状态带“趋势”和“累积量”，不是瞬时值。

**4. 空间差异真实**：同一场雨，上游和下游、山脚和河边、阳坡和阴坡影响不同。旱季时靠河近的田和靠河远的田缺水程度不同。草药分布不均匀，各在各的位置。环境事件带空间范围，不是全局一刀切。

**5. 不可逆与可逆真实**：山洪冲毁的田当年无法恢复；修渠可以恢复灌溉，但地力要几年才回来。砍掉的古树不会再生；普通林木可以再长但需要时间。人被野兽咬伤留下的伤可能终身影响体力。区分可逆变化和不可逆变化，不可逆的标记，可逆的带恢复时间和条件。

人文环境同样有节律：谣言传播需要人际接触，不是瞬间全镇皆知；制度规则不会因一次纠纷就改，要反复冲突、有人推动、有人反对才可能松动；关系变化是渐进的；舆论形成需要多人议论、多次事件累积。

**必须保真的**：因果链、时间尺度、空间差异、不可逆性、累积效应。这五条是“现实感”的骨架。**可以简化的**：具体数值精度、微观物理过程、生物细节。简化的是精度，不是逻辑。

## 五、当下快照与演化历史并存

环境不能只有“会变”，还要有“当下具体长什么样”。两条线同时存在：

- **演化历史（事件流）**：旱了多久、谁修过渠、哪片林被砍过、哪座房子什么时候盖的。回答“为什么现在是这个样子”。
- **当下快照（空间状态）**：每个节点当前的具体状态——有什么建筑、什么资源、什么人在场、什么正在发生。回答“此刻这里是什么样”。

两条线都要。只有历史没有快照，人物行动没有落脚点；只有快照没有历史，记录失去因果。

人物每个行动事件都带 `location`（节点或资源点 ID + 描述）、`scene_snapshot`（当时该位置的环境状态 + 在场人物 + 正在发生的事）、`action`（人物做了什么说了什么）。

## 六、教育：人文环境塑造人的总机制

你强调教育不止是“识字/上学/学手艺”这条窄路。在小镇里，**教育是整个人文环境持续塑造人的过程**，多数时候不是正式制度。

具体包括：

- **家庭教养**：谁带大、听什么故事、看父母怎么处理纠纷，传递价值观、性别角色、辈分规矩、生存态度。
- **生计技能**：跟着父母下田、跟船捕鱼、跟老人采药、跟母亲织布、跟师傅学木工。教育嵌入在生产里，失败也是教育。
- **社区规训**：村规、舆论、惩罚、排挤。通过围观、议论、被罚、被孤立让人学会规矩。
- **仪式与信仰**：祭山神、祭祖、婚丧节庆、禁忌，塑造世界观和“什么不能碰”。
- **信息与经验**：洪水冲过哪块田、哪条山路会滑坡、谁家借粮不还，通过老人讲述和邻里闲聊进入认知。环境事件本身就是教材。
- **代际传递与断裂**：老人教孙辈、师傅带徒弟，但年轻人可能不信老规矩、看不上旧活计，产生冲突。

对“终生在小镇的人”来说，教育线就是：**他怎么一点点变成现在这个人的**。记录里显式标出教育事件，比如“跟随父亲学犁田”“被里正训诫”“听老人讲山里禁忌”“第一次上山迷路”。

## 七、人：心理、成长、多线状态

每个人有多条状态线：

- **生理与年龄**：体力、健康、寿命，由 tick 和事件驱动。
- **能力与技能**：农事、捕鱼、采药、木工、织布、识字等，随学习和实践变化。
- **心理**：情绪、动机、人格倾向、认知、精神状态。心理不直接被规则改，而是感知事件后迁移，每次变化挂因果父事件。
- **社会关系**：亲缘、邻里、朋友、仇人、债务关系，有信任和利益权重。
- **社会地位与角色**：帮工、自耕农、工匠、里正、长老等，由事件链累积触发变化。
- **知识与记忆**：知道什么、记得谁、对谁有什么判断。
- **资源与财产**：粮食、柴薪、工具、田地、积蓄。

成长体现在这些线随事件迁移，**每次变化都能追溯到触发它的事件**。你查一生时，看到的是“因为某件事，他从什么样变成了什么样”。

---

## 八、人与人的交互：多轮拉扯

一次交互是一个**会话**，包含多个回合，不是单轮判定。

每轮里，接收方根据**当前心理状态 + 对发起方的信任度 + 自身利益诉求 + 环境压力 + 过往关系史**判断如何回应。回应可以是同意、拒绝、拖延、反问、部分接受、提条件、转移话题、情绪爆发。

说服要跨过门槛：信任门槛、利益冲突、情绪状态、关系历史、信息不对称。言语本身只是作用力之一，**人不会受到几句话的约束**。

典型拉扯：请求 → 拒绝 → 加码 → 动摇但提条件 → 讨价还价 → 部分接受 → 执行中反悔或打折扣。也可能谈崩、关系恶化。

**慎重程度随场景变化，由主观重要性决定。** 重要性由利益相关度、风险与不可逆性、信息掌握度、价值观/情绪合成。低重要性单轮快速决定；中重要性常规讨价还价；高重要性深度拉扯、试探、拖延、反悔。允许误判：他以为不重要就草率，事后才发现代价；或过度谨慎错过机会。记录里要能读出“他为什么慎重/为什么草率”。

## 九、第一版聚焦：终生在小镇的人

小镇上的人有**向上的向外的接口**，比如教育、学手艺、婚姻、里正位置、外出求学、投亲、做工、参军等。但第一版先聚焦**终生留在小镇的人**。

这些人知道通道存在，可能尝试过、犹豫过、放弃过，但一生在镇内完成。他们的“向上”尝试（学手艺、争水权、联姻、争里正位置）和“向外”念头（想走但没走、想送孩子出去但供不起）都在镇内闭环里发生。

**终生在小镇，故事不在“他去了哪”，而在“他没去哪、为什么没去、后来怎么面对这个选择”。**

接口要预留：人物属性留 `aspiration`（向上/向外意图）；事件类型留教育尝试、拜师、离开尝试等；世界配置留外部世界占位；制度规则留“可被事件挑战/修改”的口子。第一版不真正执行离开，只记录想法和镇内结果。

## 十、时间与记录

- **逻辑时间 tick 与机器时间解耦**。1 tick = 1 天。可以快进几分钟跑完几年，也可以实时慢慢过；人生长度不因机器快慢而变。
- **事件日志是唯一真相**。每个事件带 tick、参与者、动作、结果、因果父事件、位置、环境上下文、心理快照（关键节点）。
- 一个人的一生 = **事件序列 + 环境序列 + 心理序列**，按 tick 对齐。
- 记录形态：事件流水 + 关键转折 + 可读摘要/传记。要能看出因果，不是黑箱数值。

---

## 十一、接口：读写都要

- **读**：拉某人一生记录（支持增量、按类型过滤）、当前状态、所处环境；查某个区域的环境演化史和当下快照。
- **写**：向世界注入事件；附身某人实时选择，松手后 ta 继续自主生活。
- **附身**：给角色一个 `driver` 字段，`autonomous` 或 `possessed`。被附身时跳过自动决策，等待外部指令；其他人继续按 tick 演化。附身不需要暂停整个世界。
- **世界可存档、可换设定**：旧世界冻结存档仍可查；迁环境靠事件日志和配置重放。跨世界迁移角色是后续显式功能。

---

## 十二、第一版范围与验证目标

**范围**：

- 一个小镇，镇内 5–10 个建筑节点，田地 3–5 片，河流 3–5 段，山 3 层加若干具体资源点。
- 20–30 个镇民，3–5 个主角精细模拟；背景人物移动和交互先聚合，进入主角视野或被查询时展开。
- 纯规则驱动，先不接 LLM。
- 跑 1–2 年（400–700 tick）。

**验证目标**：

- 环境自己演化时，人文规则能让人做出不同选择，选择反过来改变环境，形成可追溯闭环。
- 能读出：旱季水权纠纷多轮拉扯；近山柴薪变少有人冒险进浅山；山洪冲田后谁组织修渠、谁偷懒；某人想学手艺被家里阻止、偷偷学、被发现、家庭拉扯；某人想送孩子识字但供不起、孩子后来怨他。
- 同一个人在不同处境下慎重程度不同，且记录里能读出原因。
- 教育线能显式追溯到“他怎么变成现在这个人”。
- 人物行动有具体场景锚点，不是抽象坐标。

**扩展预留**：

- 事件 `payload` 字典可加字段；规则配置驱动；世界配置分层；接口按资源设计；心理和环境状态用可扩展键值集合；tick 引擎与 API 进程分离。
- 以后加 LLM、多区域、背景精细展开、跨世界迁移，都是新增而非改写。

---

## 十三、还没定死的点

- 附身时是“每 tick 替 ta 做一个选择”就够，还是要连续多轮对话式操控、每句话即时看到反应。
- 第一版要不要就区分“客观重要性”和“主观感知重要性”，让角色可以误判。
- 制度规则第一版固定，还是允许人物通过事件修改规则（你倾向先固定，预留接口）。

## 十四、文档地图与横切层约定

### 文档地图

设计文档位于 `docs/design/`。通用机制放在 `systems/`，地点特定的地理、人口、制度参数和初始状态放在 `locations/`；地点文档引用 systems，不复制通用机制。子系统设计文档统一放在 `docs/design/systems/` 下，共 4 个子系统：

- **natural-environment（自然环境）**：`00-overview.md` + 模块 `01-spatial-skeleton`、`02-climate`、`03-hydrology`、`04-terrain`、`05-soil-and-fields`、`06-vegetation`、`07-fauna`、`08-hazards` + 横切层 `09-dynamics/`、`10-state-and-records/`。
- **human-environment（人文环境）**：`00-overview.md` + 模块 `01-social-spaces`、`02-institutions`、`03-relationships`、`04-information`、`05-education`、`06-stratification`、`07-conflicts`、`08-rituals-beliefs`、`11-livestock`（家畜资产，横切层之后） + 横切层 `09-dynamics/`、`10-state-and-records/`。
- **agents（人物）**：`00-overview.md`、`01-physical-state.md` … `06-actions.md` + 横切层 `09-dynamics.md`、`10-state-and-records.md`。
- **interaction（交互）**：`00-overview.md`、`01-session-structure.md`、`02-negotiation-dynamics.md`、`03-importance-and-pacing.md`、`04-outcomes-and-consequences.md` + 横切层 `09-dynamics.md`、`10-state-and-records.md`。

### 横切层编号约定

全局统一使用两个横切层编号，**每个子系统都必须实现**：

- **09（动力学 / dynamics）**：该子系统状态变量的变化速率、滞后与累积、空间传播、可逆性规则。内容少的子系统用单文件 `09-dynamics.md`，内容多的用目录 `09-dynamics/`。
- **10（状态与记录 / state-and-records）**：该子系统的快照结构、事件流规范、查询接口。可用单文件 `10-state-and-records.md` 或目录 `10-state-and-records/`。

每个子系统的 `00-overview.md` 末尾都应设"横切机制引用"段，指向本子系统的 09 / 10，保证跨子系统引用不迷路。
